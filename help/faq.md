# FAQ – よくある質問

## ベータ版へのアクセス

* **ベータ版ビルドにアクセスする方法を教えてください&#x200B;** \
  既存のSubstance 3Dのお客様は、Adobe IDを使用してCreative Cloudデスクトップにログインし、「ベータ版」セクションで検索できま&#x200B;。
* **Steam版はベータ版アプリにアクセスできますか&#x200B;?**\
  ベータ版ビルドは、Substanceのサブスクリプションを購入されているお客様のみが利用できます。

## Adobe、Firefly、ジェネレーティブAI

[Fireflyに関するFAQ一式にアクセス](https://www.adobe.com/jp/products/firefly.html#faqs)

* **Adobeのお客様の場合、Fireflyモデルの一部としてコンテンツのコピーを含めることはできますか？** \
  いいえ。お客様のコンテンツのコピーはFireflyモデルには含まれません。
* **Adobeのお客様の場合、コンテンツはFireflyのトレーニングに自動的に使用されますか？** \
  いいえ。 当社は、Creative Cloudサブスクライバーの個人コンテンツに関するトレーニングは行いません。 Adobe Stockコントリビューターの場合、コンテンツは、Stock Contributorライセンス契約に従ってFireflyトレーニングデータセットに含まれます。
* **Adobeは、データセット内でコンテンツが使用されているAdobe Stockコントリビューターに対して、Fireflyモデルをトレーニングするために補償を行う計画を立てています。また、補償プランはどうなりますか？** \
  Adobe Stockコントリビューター向けの報酬モデルを用意しています。 詳しくは、 Adobe Stockに関するよくある質問を参照してください。
* **AIが生成した画像を責任を持って確実に作成するために、Adobeは何をしていますか？** \
  アドビでは、Fireflyを商業的に安全なものにするためにデザインするAdobeの取り組みの一環として、Adobe Stockなどのライセンスコンテンツや、著作権が期限切れのパブリックドメインコンテンツに関する初期の商用Fireflyモデルのトレーニングを行っています。 さらに、Content Authenticity Initiative(CAI)の共同創設者として、Adobeは責任あるAI生成のための業界標準を確立しています。 CAIは、メディアやテクノロジー企業、NGO、学者などで構成されるコミュニティであり、コンテンツの信頼性と来歴に関するオープンな業界標準の採用を促進しています。
* **Adobe Firefly Image 2モデルとは** \
  Adobe Firefly画像2は、モデルのFireflyファミリーに含まれる画像生成モデルの次のバージョンです。
