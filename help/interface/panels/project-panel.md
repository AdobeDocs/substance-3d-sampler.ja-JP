# プロジェクトパネル

![](../../assets/Project-panel-gen.png)

Samplerのプロジェクトは、複数のアセットを格納できるパッケージのように機能します。 **プロジェクトパネル**&#x200B;には、現在のプロジェクトを構成するマテリアルが表示されます。

プロジェクトパネルの上部にあるコントロールを使用すると、現在のプロジェクトにマテリアルを追加または管理できます。

* 「**追加**」ボタンを使用して、**マテリアルプリセットメニュー**&#x200B;を開き、プロジェクトに新しいマテリアルを追加します。
* 現在選択されているマテリアルを複製するには、**[複製]**&#x200B;ボタンを使用します。
* 現在選択されているマテリアルの名前を変更するには、**名前の変更**&#x200B;ボタンを使用します。
* 現在選択されているマテリアルを削除するには、**[削除]**&#x200B;ボタンを使用します。

>[!NOTE]
>
> マテリアルを右クリックして、名前を変更、削除、または複製することもできます。

いずれかのアセットをクリックして&#x200B;**ビューポート**&#x200B;に読み込むか、マテリアルを&#x200B;**レイヤーパネル**&#x200B;にドラッグして他のマテリアルで使用します。
