# 表示されるパラーメーターパネル

![](../../assets/ezgif-com-gif-maker-7.gif)

**表示されるパラーメーターパネル**&#x200B;には、**プロパティパネルから公開されるパラメーターが含まれています。**

色付きの点は、パラメータがどのレイヤに接続されているかを視覚化するのに役立ちます。 空のドットは、パラメーターがブレンドレイヤーからであることを示します。

![](../../assets/ezgif-com-gif-maker-1.gif)

公開されたパラメーターを操作するには、いくつかの方法があります。

| アクション | 方法 |
| --- | --- |
| パラメーターの公開を解除 | パラメーターを右クリックし、「公開しない」を選択します。 |
| パラメーターのラベルの編集 | パラメータを右クリックして[編集]を選択し、新しいラベルを入力します。 |

**プロパティパネルを使用すると、通常どおり、すべてのパラメーターを操作できます。** 変更は3Dビューポートに反映されます。
