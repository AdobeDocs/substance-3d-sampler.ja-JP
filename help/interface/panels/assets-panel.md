# アセットパネル

![](../../assets/Assets-panel-gen.png.img.png)

**アセットパネル**&#x200B;には、作品の作成に使用できるアセットが含まれています。 Samplerには、作業を始めるのに役立つマテリアル、フィルター、テクスチャジェネレーターのコレクションが含まれています。

**アセットパネル**&#x200B;には、アセットを整理して見つけるのに役立つコントロールがいくつかあります。

* 検索バーを使用して、アセットをすばやく検索します。
* タイプでアセットをフィルタリングします。
* アセットをタイプ別またはカテゴリ別にグループ化します。
* リスト表示とアイコン表示を切り替えます。

## アセットパネルへのアセットの追加

独自のアセットをアセットパネルに追加するには、**アセットパネル**&#x200B;の右下にある&#x200B;**+**&#x200B;をクリックします。 アセットの場所を参照して選択し、[**開く**]をクリックします。 カスタムアセットを&#x200B;**アセットパネル**&#x200B;からごみ箱の上にドラッグして削除できます。

## 追加のチャンネルを有効にする

アセットパネルからレイヤースタックにマテリアルをドラッグ&amp;ドロップすると、余分なチャンネルをアクティブにするよう求められることがあります。 この機能は、アセットで現在アクティブ化されていないチャンネルがマテリアルから出力された場合に提供されます。 異方性効果やコーティングなど、複雑な素材を利用する場合は、この機能を有効にします。

![レイヤースタックにマテリアルが追加されると、チャネルのアクティブ化がポップアップします](../../../help/assets/sampler_assets-panel_additional-channels-activation.png)

>[!NOTE]
>
> **アセットパネル**&#x200B;で削除できるのはカスタムアセットのみです。 Samplerのデフォルトアセットを削除することはできません。
