# 書き出しパネル

<b>書き出しパネル</b>では、アセットを一般ファイルとして書き出したり、アセットを他のアプリケーションに直接送信したりできます。

## 送信先...

「送信… 」オプションを使用すると、システムにインストールされている他のアプリケーションにアセットを直接送信できます。 通常、この方法は、アセットの読み込みと書き出しよりも高速です。

現在、Samplerでは以下への送信をサポートしています。

* **Substance 3D Painter**:アセットのテクスチャリング中に使用できるマテリアルと環境を読み込みます。
* **Substance 3D Stager**：環境光を読み込んで、シーンの雰囲気を変えます。 環境光でのみ使用でき、マテリアルでは無効です。

マテリアルは常にSBSAR、環境はEXRとして送信されます。

## 書き出し

**[書き出し形式…]**&#x200B;をクリックして、現在作業中のアセットを書き出します。 左側のメニューから、「一般設定」または「マテリアル設定」を変更するかどうかを選択します。

### 一般設定

[一般設定]を選択すると、マテリアルの名前と保存場所を変更できます。 また、マテリアルのサブフォルダを作成するかどうかを切り替えることもできます。 これは、複数のファイルが作成される画像形式で書き出す場合に便利です。

### マテリアル設定

マテリアル設定を選択すると、マテリアルの書き出し方法をコントロールするために、次の各種パラメータを変更できます。

| 設定 | 説明 |
| --- | --- |
| 書式設定 | SBS、SBSAR、または特定の画像形式の画像のコレクションとして書き出すかどうかを選択します |
| プリセット | プリセットを選択して、特定のアプリケーション用に書き出しを自動的に整理します。 [プリセットの詳細については、こちらを参照してください](../../getting-started/export/default-presets/default-presets.md)。 プリセットは、画像形式が選択されている場合にのみ使用できます。 |
| 圧縮 | 圧縮で速度と効率のどちらを優先するかを選択します<br> <ul> <li> **自動**: Samplerで選択できるようにします。 <li> **最高** ：小さいファイルの圧縮効率を最大化します。 <li> **なし**：圧縮なしでは、書き出されたファイルを開いたり閉じたりするのが速くなりますが、ファイルサイズは大きくなります。 </ul> |
| 解決策 | エクスポートの解像度を変更します。 このオプションは、選択されている形式によって異なります<br> <ul> <li> **SBSAR/SBS**:マテリアルの既定の幅とHeightを選択します。 これらは後で更新できます。 <li> **画像の形式**:レイヤースタックで定義されたサイズで各マップを書き出す&#x200B;**レイヤー出力**&#x200B;を選択するか、書き出す幅とHeightを指定できる&#x200B;**すべてをオーバーライド**&#x200B;します。 |
| マテリアルモデル | Adobe Standardマテリアルとして書き出すか、OpenPBRマテリアルとして書き出すかを選択します。 選択するオプションは、パイプラインで使用している他のアプリケーションによって異なります。 マテリアルモデルに応じて、様々なチャンネルが使用できるようになります。 |
| チャネル | アセットの一部として書き出すチャンネルを切り替えます。 |

>[!NOTE]
>
> 書き出しダイアログのオプション、およびファイル形式などのその他の情報について詳しくは、書き出しウィンドウの[書き出し記事](../../getting-started/export/export.md)とその[サブ記事](../../getting-started/export/export-window/export-window.md)を参照してください。

書き出し設定が完了したら、「**書き出し**」をクリックします。 書き出しは、書き出しキューに表示されます。このキューには、最近の書き出しのリストが表示されます。 任意の書き出しのフォルダーアイコンをクリックして、その書き出しのファイルの場所を開きます。
