# レイヤーパネル

<table>
<tr style="border: 0;">
<td style="border: 0; width: 70%" valign="top">

**レイヤーパネル**&#x200B;には、レイヤーのスタックと、レイヤーを管理するためのショートカットが含まれています。 **レイヤーパネル**&#x200B;は、**プロパティパネル**&#x200B;と連携します。**レイヤーパネル**&#x200B;でレイヤーを選択し、**プロパティパネルでプロパティを確認します。**

**レイヤーパネル**&#x200B;は、次の3つの主要なセクションで構成されています。

1. ツールセクションには、次の操作に使用できるボタンが表示されます
   1. レイヤー解像度の表示/非表示
   1. レイヤー解決戦略の切り替え
   1. レイヤーを追加
   1. ベースマテリアルを追加
   1. カスタムフィルターの読み込み
   1. レイヤーを削除
1. **描画モードセレクター**&#x200B;を使用すると、レイヤーとその下にあるレイヤーの描画方法を調整できます。 **描画モードセレクター**&#x200B;は、マテリアルレイヤーが選択されている場合にのみ使用できます。フィルターでは描画モードは使用されません。
1. **レイヤースタック**&#x200B;には、アセットを構成するすべてのレイヤーが含まれています。

## レイヤースタック

レイヤースタックは、現在のマテリアルを構成するマテリアル、フィルター、およびその他のリソースのコレクションです。 PhotoshopやSubstance 3D Painterと同様に、レイヤースタックは下のレイヤーから最初に作業し、上のレイヤーから最後に作業します。 つまり、各レイヤーはその下のレイヤーに影響を与える可能性があります。

レイヤースタックを管理するには、いくつかの方法があります。

| アクション | 方法 |
| --- | --- |
| レイヤーを追加 | **アセットパネル**&#x200B;からアセットをビューポートにドラッグして、レイヤースタックの先頭に追加します。 **アセットパネル**&#x200B;からアセットをレイヤースタックにドラッグして、レイヤースタックの特定の場所に追加します。 [ツール]セクションの[**レイヤーの追加**]ボタンを使用して、一覧からフィルターを選択します。 |
| レイヤーの移動 | レイヤースタックのレイヤーをドラッグして移動します。 レイヤーを移動すると、レイヤーの配置場所を示すバーが表示されます。 |
| レイヤーの削除 | レイヤーをクリックして選択し、**Del**&#x200B;を押すか、ツールセクションの&#x200B;**レイヤーを削除**&#x200B;ボタンを使用します。 |
| 表示を切り替え | レイヤーの上にマウスポインターを置くと、レイヤーの右側に&#x200B;**表示/非表示の切り替え**&#x200B;が表示されます。 レイヤーの表示/非表示を切り替えても、レイヤーは計算されません。 |
| レイヤープロパティを表示 | レイヤーをクリックして、**プロパティパネルでそのプロパティを表示します。** |
| 解像度を表示/非表示 | **レイヤーパネル**&#x200B;の左上のボタンをクリックします。 |
| すべてのレイヤー解像度を切り替え | 「解像度を表示/非表示」ボタンの横にある矢印をクリックして、スタックのすべてのレイヤーの戦略を選択します。 |
| レイヤー解像度の切り替え | レイヤーをクリックしてそのプロパティを開き、**プロパティパネル**&#x200B;で解像度をクリックして、レイヤーで使用する解像度の戦略を選択します。 |

## レイヤーの種類

レイヤーには次の3種類があります。

* マテリアル
* フィルター
* 画像

### マテリアルレイヤー

マテリアルレイヤーは、複数のチャンネルに情報を含み、その下のレイヤーとブレンドできます。 マテリアルレイヤーは、スタックの一番下にあるかどうかによって若干異なって表示されます。 例えば、下の画像では岩のマテリアルを2回レイヤースタックにドラッグしています。下のレイヤーにはブレンドを制御するアイコンがなく、上のレイヤーにはブレンドを制御するアイコンがないことに注意してください。

![レイヤースタックのマテリアルレイヤー。最上位レイヤーには描画オプションがあります。](../../assets/Material-Layer.png)

マテリアルレイヤーの一般的な規則は次のとおりです。

* マテリアルレイヤーは常にドキュメント解像度を使用します。
* スタックの一番下のマテリアルレイヤーにはブレンドする要素がないため、**描画モードセレクター**&#x200B;は使用できません。
* スタックの一番下にないマテリアルレイヤーは、その下にあるレイヤーとブレンドできるので、**描画モードセレクター**&#x200B;を使用して描画モードを変更できます。 さらに、**ブレンドアイコン**&#x200B;が&#x200B;**レイヤーアイコン**&#x200B;の横に表示されます。 **描画アイコン**&#x200B;を選択して、描画モードが選択されたレイヤーの描画設定を調整します。

### レイヤーのフィルター

![以下のレイヤーを調整する色相/彩度フィルターのプロパティ。](../../assets/HueSaturation_LayerFilter.gif)

フィルターはその下のレイヤーに対して操作を実行し、特定のエフェクトを作成します。 例えば、**色相・彩度フィルター**&#x200B;の上の画像では、下のレイヤーの色相、彩度、明度を調整できます。

一部のフィルターは、1つ以上の他のレイヤーを入力として取ることができます。 以下に例を示します。

* **Atlas Scatterフィルター**&#x200B;は、マテリアルを入力として受け取ることができます。
* **Atlas Scatterフィルター**&#x200B;は、**Atlas Scatter**&#x200B;パラメーターに基づいて、入力アトラスマテリアルからインスタンスを散乱します。

マテリアルをレイヤ入力スロットにドラッグして、入力として使用します。

フィルターレイヤーでは、環境設定で設定されたデフォルトの解像度を使用します。 フィルターの解像度は、プロパティパネルで変更できます。

![フィルターレイヤーの解像度の切り替え](../../assets/SwitchLayerResolution.gif)

### 画像レイヤー

画像レイヤーは独自の解像度を使用し、主に画像からマテリアルへのワークフローにあります。 マテリアルレイヤーと同様に、**アセットパネル**&#x200B;から画像をドラッグして画像レイヤーを作成できます。

画像をシステムのファイルブラウザーからSamplerにドラッグできます。レイヤースタックに既にレイヤーがある場合、画像レイヤーはスタックの一番上に追加されます。 レイヤースタックにレイヤーがない場合は、ダイアログが表示され、画像の処理方法を選択できます。

* **画像をマテリアルに**&#x200B;すると、AIを使用して画像をマテリアルに変換できます。
* **マルチアングルからマテリアル**&#x200B;では、照明条件が異なる複数の画像を使用して素材を作成できます。
* **テクスチャの読み込み**&#x200B;を使用すると、読み込んだ画像をテクスチャチャンネルとして使用して、マテリアルを作成できます。
* **ビットマップとして使用** ：画像を単純なビットマップレイヤーとして読み込みます。

選択した複数の画像を一度にレイヤースタックにドラッグして、1つのレイヤーとしてすべて読み込むこともできます。 これは、**HDR結合**&#x200B;や&#x200B;**マルチアングルからマテリアル**&#x200B;などの複数画像フィルターで役立ちます。 複数の画像を含むレイヤーを選択して、各画像のチャンネルデータを変更します。
