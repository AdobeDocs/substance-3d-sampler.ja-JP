# サイドバー

Samplerには、**左サイドバー**&#x200B;と&#x200B;**右サイドバー**&#x200B;の2つのサイドバーがあります。

![](../assets/Sidebars.png)

## 左サイドバー

**左側のサイドバー**&#x200B;では、次のことができます。

* **コンテンツの追加とインポート**：画像をインポートし、プロジェクトへの統合方法を選択します。
* **3Dアセットを参照**: Creative Cloudデスクトップ内のSubstance 3D Assetsから数千のマテリアルにアクセスします。
* **クイックアクション**&#x200B;にアクセス：特定の目標をすばやく達成するためのアクションのコレクションです。 [**クイックアクション&#x200B;**](../features-and-workflows/quick-actions.md)**の詳細情報。**
* フィルターにすばやくアクセスできます。
* 次のパネルを閉じたときに再度開く：
  * **クイックアクションパネル**。
  * **プロジェクトパネル**。
  * **アセットパネル**。
  * **チャネル設定パネル**。

**左サイドバー**&#x200B;から利用できるフィルターの詳細については、「[ツールとウィジェット](tools-and-widgets/tools-and-widgets.md)」を参照してください。

## 右サイドバー

**右サイドバー**&#x200B;は、閉じたときに次のパネルを保持します：

* **レイヤーパネル**。
* **プロパティパネル**。
* **表示されるパラーメーターパネル**。
* **物理サイズパネル**。
* **メタデータパネル**。
* **書き出しパネル**

## サイドバーからのフィルターの追加

**左側のサイドバー**&#x200B;を使用すると、フィルターにすばやくアクセスできます。 フィルターアイコンにカーソルを合わせてフィルター名を表示し、フィルターをクリックすると、そのフィルターがすぐにスタックに追加されます。

フィルターを右クリックして、関連するフィルターのリストを表示することもできます。 例えば、**タイリング**&#x200B;フィルターを右クリックすると、**自動タイリング**&#x200B;および&#x200B;**タイルにする**&#x200B;フィルターにアクセスできます。

>[!NOTE]
>
> **右クリックメニュー**&#x200B;を使用してフィルターを追加すると、**サイドバー**&#x200B;にある元のフィルターが最後に使用したフィルターに置き換えられます。
>
> 例えば、次のアニメーションでは、**イコライズフィルター**&#x200B;が表示されています。 右クリックして&#x200B;**フォールド除去フィルター**&#x200B;を追加すると、**サイドバー**&#x200B;の&#x200B;**イコライズフィルター**&#x200B;が&#x200B;**フォールド除去フィルター**&#x200B;に置き換えられます。
>
> ![](../assets/quick-filter-replacement.gif)
