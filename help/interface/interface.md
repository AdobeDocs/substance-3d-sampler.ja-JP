# インターフェイス

Samplerのワークスペースは、2Dおよび3Dビューポート、左右のサイドバー、パネルのコレクションで構成されています。 各パネルは特定の目的に特化されているため、クリエイティブプロセスの様々な部分で様々なパネルが役立ちます。

## ワークスペースの概要

ワークスペースは、Samplerで時間のほとんどを過ごす場所です。 デフォルトでは、ワークスペースは6つの領域で構成されています。</td>
<td style="border: 0;" valign="top">

A. <b>アプリケーションメニューバー</b>には現在のプロジェクト名が表示されます。 また、「ファイル」、「編集」、「ウィンドウ」、「ヘルプ」、「ライセンス」の各メニューも保持します。\
B. **左側のサイドバー**&#x200B;では、次のことができます。

* コンテンツを追加して読み込みます。
* Creative Cloudデスクトップで3Dアセットを参照します。
* クイックアクションにアクセス
* 一般的なツールにすばやくアクセスできます。
* **チャンネル設定パネル**&#x200B;を開きます。

C. <b>プロジェクト</b>および<b>アセットパネル。</b>
D. <b>2D </b>および<b>3Dビューポート</b>には、現在作業中のアセットが表示されます。\
E. <b>レイヤー</b>と<b>プロパティパネル。</b>
F. **右側のサイドバー**&#x200B;から、次のパネルにアクセスできます。

* 表示されるパラメーター
* 物理サイズ
* メタデータ
* 書き出し

<b>アプリケーションメニュー</b>の詳細については、以下で説明します。 **[パネル](panels/panels.md)**、**[ビューポート](2d-and-3d-viewport.md)**&#x200B;および&#x200B;**[サイドバー](sidebars.md)**&#x200B;には、それぞれ独自の記事があります。

## ワークスペースのカスタマイズ

Samplerのワークスペースはすべてカスタマイズ可能なので、自分に合ったレイアウトを見つけることができます。 パネルを初期設定のレイアウトにリセットする場合は、**ウィンドウ/初期設定のレイアウトにリセット**&#x200B;を使用します。

## パネルの再配置

パネルのタイトルをクリックしてドラッグし、移動を開始します。

パネルをビューポートまたは他のパネルの端にドッキングするには、パネルをドッキングする端の上にパネルをドラッグします。青いハイライトガイドが表示されます。 線が表示されたら、パネルをドロップしてドッキングします。

## パネルを開く/閉じる

パネルを閉じるには、パネルの右上にあるXを使用します。 閉じたパネルはサイドバーに保存されます。

パネルを再度開くには、左右のいずれかのサイドバーで、パネルに関連するアイコンをクリックします。 パネルが一時的に開きます。 パネルが完全に開いた状態にするには、パネルを外側にドラッグします。

## アプリケーションメニュー

**アプリケーションメニューバー**&#x200B;には、現在のプロジェクト名が表示されます。 また、**ファイル**、**編集**、**ウィンドウ**、**ヘルプ**、**ライセンス**&#x200B;の各メニューも含まれています。

<b>ファイル</b>メニューを使用して、新しいプロジェクトを作成したり、既存のプロジェクトを開いたり、現在のプロジェクトを保存またはエクスポートしたりします。

<b>編集</b>メニューを使用して、操作を取り消したりやり直したり、[環境設定](../interface/preferences/preferences.md)を開いたりすることができます。

<b>ウィンドウ</b>メニューを使用して、ワークスペースを既定のレイアウトにリセットします。

Samplerについて詳しくは、<b>ヘルプ</b>メニューを使用してください。また、問題の解決方法についても説明します。
