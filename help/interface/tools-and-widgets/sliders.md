# スライダー

![](../../assets/sliders-basic.gif)

1つから複数のスライダーをアニメーション化するオプションがあります。 **Ctrl**&#x200B;を押してスライダーにカーソルを合わせると、**再生**&#x200B;アイコンが表示され、アニメーションが起動します。

アニメーションを一時停止するには、**Ctrl**&#x200B;を押します。アニメーション化されたスライダーにカーソルを合わせると、**一時停止**&#x200B;アイコンが表示され、このスライダーのアニメーションを停止できます。

すべてのスライダーを一時停止する場合は、**P**&#x200B;を押します。再起動するには、もう一度&#x200B;**P**&#x200B;を押します。
