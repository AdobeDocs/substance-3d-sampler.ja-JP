# 不具合を報告

Sampler内からバグを報告できます。

<b>ヘルプ</b>メニューを開き、<b>ブーを報告</b>gを選択してください：

![](../assets/Bug-report-howto.png.img.png){width="700px"}

次のフォームに入力します。

![](../assets/Bug-report-window.png.img.png){width="400px"}

その後、「送信」をクリックします。 入力した情報は、Sampler開発チームに直接送信されます。
