# 書き出し

**ファイルメニュー**&#x200B;の&#x200B;**書き出し形式**&#x200B;を選択するか、ショートカット&#x200B;**Ctrl + E**&#x200B;を使用して、アセットを書き出すことができます。これにより、[書き出しウィンドウ](../../getting-started/export/export-window/export-window.md)が開き、書き出しをカスタマイズできます。

>[!NOTE]
>
> **書き出しウィンドウ**&#x200B;で「マテリアルモデル」オプションを変更すると、書き出されるファイル名が選択したマテリアルモデルと一致するように変更されます。

![マテリアル設定を選択した状態でウィンドウを書き出し](../../assets/6.0_ExportWindowMaterialSettings.png)

Samplerは、アセットの主要なファイル形式をサポートしています。

* マテリアルは、**SBS**&#x200B;または&#x200B;**SBSAR**&#x200B;ファイルとして書き出すことができます。
* また、マテリアルは、次のファイル形式でチャンネルごとのビットマップテクスチャを書き出すことができます。
  * **EXR**
  * **JPEG**
  * **PNG**
  * **TARGA**
  * **TIFF**
  * **USDA**
  * **USD**
  * **USDZ**
