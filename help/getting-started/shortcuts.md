# ショートカット

このページには、使用可能なすべてのキーボードショートカットとそのアクションが一覧表示されます。

## グローバルショートカット

| *アクション* | *ウィンドウ* | *MacOS* |
| --- | --- | --- |
| 元に戻す | Ctrl + Z | ⌘ + Z |
| やり直す | Ctrl + Shift + Z | ⌘ + Shift + Z |
| 保存 | Ctrl + S | ⌘ + S |
| 別名で保存 | Ctrl + Shift + S | ⌘ + Shift + S |
| 書き出し | Ctrl + E | ⌘ + E |
| 3Dビューのみ | 3 | 3 |
| 2Dビューのみ | 2 | 2 |

## 3Dビューのショートカット

| *アクション* | *ウィンドウ* | *MacOS* |
| --- | --- | --- |
| カメラの回転 | Alt +マウスを左またはマウスを左に移動 | Option +マウスを左またはマウスを左に移動 |
| カメラパン | Alt +マウス中央またはマウス中央 | Option +マウス中央またはマウス中央 |
| カメラズーム | Alt+マウスの右向きまたはマウスホイール | Option +マウスの右向きまたはマウスホイール |
| 焦点 | F | F |
| 環境の回転 | Shift +マウスの右向き矢印 | Shift +マウスの右向き矢印 |
| 環境の表示 | 1 | 1 |
