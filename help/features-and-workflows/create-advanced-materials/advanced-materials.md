# 高度なマテリアルを作成

[OpenPBR](../openpbr.md)を使用すると、[ファズ](fuzz.md)、[水面](subsurface.md)、[コーティング](coating.md)などのチャンネルを使用して、興味深い効果を生み出すことができます。 通常、これらのチャンネルは特定のコンテキストでのみ使用され、粗さやベースカラーなどの一般的に使用されるチャンネルとは少し異なる動作になる場合があります。

- [毛羽立ち](fuzz.md)
- [サブサーフェス](subsurface.md)
- [コート](coating.md)
