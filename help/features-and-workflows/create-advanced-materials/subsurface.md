# サブサーフェスチャンネルの操作

サブサーフェスチャンネルは、不透明だが半透明のマテリアルに便利で、マテリアルのサーフェスの下に光が散乱する効果を模倣しています。 この効果は、通常、皮膚、葉、多くのプラスチックなどのマテリアルで発生します。 サブサーフェスパラメータの詳細とレジンマテリアルの作成については、以下のビデオをご覧ください。
