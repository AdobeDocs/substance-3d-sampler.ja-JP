# サブサーフェスチャンネルの操作

サブサーフェスチャンネルは、不透明だが半透明のマテリアルに便利で、マテリアルのサーフェスの下で光が散乱する効果を模倣します。 この効果は、通常、皮膚、葉、多くのプラスチックなどの材料で発生します。 下のビデオを見て、サブサーフェスパラメータの詳細を確認し、これらを使用して樹脂材料を作成してください。
