# コーティングチャンネルの操作

名前が示すように、コーティングチャンネルを使用すると、マテリアルにコーティングを加えることができます。 コーティングは独自のラフネス値を持つことができ、マテリアルの基本ラフネスに影響を与え、ニス仕上げや研磨面のような効果を生み出すのに役立ちます。 Samplerでコーティングチャンネルを使用して、ニス仕上げの寄木細工フロアのマテリアルを一から作成する方法については、以下のビデオをご覧ください。
