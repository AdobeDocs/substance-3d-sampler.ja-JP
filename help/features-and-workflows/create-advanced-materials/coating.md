# コーティングチャンネルの操作

名前が示すように、コーティングチャンネルを使用すると、材料にコーティングを追加できます。 コーティングには独自の粗さの値を設定できます。これは、材料のベースの粗さに影響を与え、ニス仕上げや研磨された表面のような効果を生み出すのに役立ちます。 Samplerのコーティングチャンネルを使用して、ニス仕上げの寄木細工の床マテリアルを最初から作成する方法については、以下のビデオをご覧ください。
