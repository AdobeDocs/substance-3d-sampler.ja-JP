# クイックアクション

![](../assets/Quactooltip.png)

クイックアクションは、数回のクリックでアセットを作成したり、スタックに多数のレイヤーを追加したりできるシステムです。 クイックアクションを使用して、アセットを作成、プロジェクトを作成、または必要なレイヤーを既存のスタックに追加します。

クイックアクションはSamplerのいくつかの場所で見つかります。

* [ホーム画面](../interface/the-home-screen.md)
* [新規ウィンドウを作成](../getting-started/project-management.md)
* [クイックアクションパネル](../interface/panels/quick-actions-panel.md)

| クイックアクション名 | 説明 | レイヤー |
| --- | --- | --- |
| 画像をマテリアルに変換 | 1 つの画像から必要なチャンネルをすべて含むマテリアルを作成します。 | 入力イメージをマテリアルAIにイコライズ |
| 複数の角度の画像をマテリアルに変換 | 異なるライト角度から撮影したサーフェスの写真をマージしてマテリアルを作成する | 入力マルチアングルからマテリアルイコライズ |
| テクスチャを読み込み | テクスチャマップからマテリアルを作成します。 | 入力 |
| 画像を読み込み | 空のマテリアルを作成し、単一の画像をレイヤーとして追加します。 | 入力 |
| 画像を刺繍に変換 | プロシージャルフィルターを適用して、刺繍パッチのような画像にします。 | 刺繍を入力 |
| 布地マテリアルを作成 | プロシージャルフィルターを使用して布地マテリアルを作成します。 | ClothWeave |
| 画像を調整 | フィルターを選択し、画像を微調整してマテリアルで使用できるように準備します。 | 入力切り抜きタイリングの明るさ/コントラストの色相/彩度のカラーの置き換え |
| 空のマテリアルを作成 | チャンネルのないマテリアルを作成します。 | なし |

## クイックアクションの使用方法

<b>ホーム画面から</b>

クイックアクションをクリック

![](../assets/clickquickaction-ezgif.com-video-gif-converter.gif)

または、クイックアクションに画像をドラッグ&amp;ドロップします。

![](../assets/dndquickaction-ezgif.com-video-gif-converter.gif)

または、クイックアクションに画像をドラッグ&amp;ドロップします。

<b>新規作成から</b>

クイックアクションまたはファイルの読み込みを選択し、入力に使用できるクイックアクションを確認します

![](../assets/createnew-1.png)

<b>クイックアクションパネルから</b>

クイックアクションをクリックして、スタックに追加するか、クイックアクションの種類に応じて新しいアセットを作成します。

* <b>適用：</b>アクティブなスタックにクイック操作を適用します。
* <b>設定：</b>スタックに追加する前に、クイック操作を事前に調整するための設定ウィンドウを開きます。
* <b>新しいアセットの作成：</b>選択したクイックアクションから新しいアセットを作成します。
* <b>新規プロジェクトの作成： </b>選択したクイックアクションから新規プロジェクトを作成します。
