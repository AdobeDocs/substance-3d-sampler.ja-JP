# レイヤーを統合

レイヤーの統合は、パフォーマンスを向上させ、レイヤースタックを簡素化するための便利な方法ですが、レイヤーの統合がプロジェクトに与える影響を認識することが重要です。

## レイヤーを統合ボタンの機能

レイヤーを統合は、現在選択されているレイヤーのすべてのレイヤーを1つのレイヤーに結合します。 統合後のレイヤーは、元のレイヤーと同じ外観になりますが、元の個々のレイヤーを調整することはできません。

### レイヤーを統合する理由

レイヤースタック内のレイヤーを変更するたびに、Samplerはそのレイヤーとその上にあるすべてのレイヤーの出力を再計算する必要があります。 計算する各追加レイヤーは、追加の処理時間とメモリ使用量を意味します。 複数のレイヤーを統合すると、それらのレイヤーの処理に必要な時間とメモリの量が減少します。 例えば、Samplerでは、10個のレイヤーを再計算するのではなく、1つのレイヤーのみを処理する必要があります。

さらに、レイヤーを統合すると、レイヤースタックが単純になるため、移動してわかりやすくなります。

### レイヤーを統合すべきでない場合

統合されたレイヤーは、レイヤースタックで個別にアクセスできないため、統合された結果のパラメーターを変更することはできません。 そのため、レイヤーの結果を変更する必要がなくなった場合にのみ、レイヤーを統合してください。

## 統合されたレイヤーパラメーター

元のレイヤーのパラメーターは失われますが、統合されたレイヤーには独自のパラメーターのセットがあり、それらを調整して結果の各チャンネルの使用方法を制御できます。

各チャンネルで、次の操作を実行できます。

* <b>出力の使用法</b>：出力を使用するチャネルを変更します。 レイヤーを統合すると、TIFFが作成され、各チャンネルに名前が付けられ、そのチャンネルに自動的に割り当てられます。
* <b>アルファチャンネルの不透明度</b> ：不透明度がAlphaチャンネルの結果に基づくかどうかを切り替えます。
* <b>削除</b>：このレイヤーからチャンネルを削除します。 これは、役に立つ情報を含まないチャンネルに役立ちます。 例えば、すべてのホワイトの不透明度チャンネルを削除すると、視覚的な結果に影響を与えずにメモリを解放できるので、お勧めします。
