## パラメーター

**基本パラメーター**

* **ランダムシード**:\
  ランダムシードは、このフィルターのランダム度を使用する他のパラメーターのランダム値を決定します。
* **数量**: 0 ～ 1\
  マテリアル全体に広がる砂利の量を変更します。
* **原色**:カラーの選択\
  砂利石のベースカラーを選択します
* **第2カラー**:カラーの選択\
  砂利石の第2カラーを選択します
* **下のマテリアルの色の一致**: 0-1\
  下になっているマテリアルのカラーが砂利のカラーに与える影響を調整します
* **キャビティマスクを有効にする**：切り替え\
  有効にすると、砂利がキャビティを埋め、材料のより高い部分に広がりません。 これにより、よりリアルな砂利の散布が可能になります。
* **散布ボリュームのしきい値**: 0 ～ 50\
  Heightの値に基づいて散布の量を調整する
* **ランダムマスク**: 0 ～ 1\
  砂利をランダムにマスクアウトする割合を設定します
* **石のサイズ**: 1 ～ 10\
  石のサイズを調整
* **石のサイズのバリエーション**: 0-1\
  サイズのランダム度を調整
* **石の丸み**: 0 ～ 1\
  石を丸くまたはangularにする
* **石の粗さ**: 0 ～ 1\
  石の粗さの値を変更する
* **石のHeight**: 0 ～ 1\
  石のHeightを変更します。 これは、石が下にあるマテリアルとどのようにブレンドされるかに影響します。
* **石の高さ**: 0-1石の基準高さを変更します。 高さは石が置かれている場所の床を設定し、Heightは石が床から離れるHeightを設定します。
* **石の標高ランダム**: 0-1\
  各ストーンの標高にランダム値を追加します。
* **サーフェスSmoothness**: 0-1\
  石の上部を滑らかにする
* **カスタムマスクを使用**：切り替え\
  カスタムマスクを使用して石の場所をペイントできるようにするか、無効にします。 次のパラメーターは、**[カスタムマスクの使用]**&#x200B;が有効になっている場合にのみ表示されます。
  * **マスクぼかし**: 0-1\
    ペイントしたマスクのエッジをぼかす
  * **カスタムマスク**：画像/ブラシ\
    ブラシをクリックして、石が表示されるカスタムマスクをペイントします。 正方形をクリックして、マスクとして使用する画像を読み込みます。

**詳細パラメーター**

* **表面サイズ(cm)**: 0 ～ 1000\
  マテリアルによって表されるサーフェスのサイズを変更します。 面のサイズを大きくすると、砂利の物理サイズが大きくなり、それに応じて砂利が変更されます。
* **深度** **(cm)**: 0 ～ 100\
  マテリアルのHeightマップで表される物理深度を変更します。 Heightの深度が高くなると、結石の物理サイズが予想より高くなるため、結石の強度は通常より高くなります。
