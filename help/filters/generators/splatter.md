## パラメーター

**基本パラメーター**

* **ランダムシード**:\
  ランダムシードは、このフィルターのランダム度を使用する他のパラメーターのランダム値を決定します。
* **マテリアル入力**:\
  入力値として使用するマテリアルの数を選択します。 注： 3つの入力スロットを持つスプラッタレイヤで、入力が入っている1つのスロットだけが表示されている場合は、1つの入力スロットと同じ入力が入っているスロットを持つスプラッタレイヤとは表示が異なります。 このため、必要な数の入力のみを使用することをお勧めします。
* **グリッドサイズ**: 1 ～ 64\
  グリッドサイズによって、スプラッタフィルタによって作成されるインスタンスの数が決まります。
* **AO深度**: 0-1\
  フィルターによって作成されたインスタンスのAOの強さを調整します。

**図形**

* **スケール**: 0 ～ 5\
  すべてのインスタンスの基本サイズを調整
* **ランダムにスケール**: 0 ～ 1\
  インスタンスごとにスケール値のランダム度を調整する
* **スケール（重なりを除く）**: 0 ～ 1\
  重なりを避けるためにインスタンスのサイズを変更
* **ランダムな位置**: 0 ～ 2\
  インスタンスの散布のランダム度を制御
* **ランダムな回転**: 0 ～ 1\
  インスタンスの回転のランダム度を制御
* **背景勾配からの回転**: 0 ～ 1\
  基礎となるマテリアルの法線がインスタンスの回転にどれだけの影響を与えるかを修正します。

**Base color**

* **アルベドの一致**: 0 ～ 1\
  インスタンスの色を基になるマテリアルの色に一致させる
* **HSL調整**: 0 ～ 1\
  インスタンスの色相、彩度、明度を調整する
* **HSLランダム**: 0 ～ 1\
  各インスタンスの色相、彩度、明度のランダム度を制御します

**標準**

* ****&#x200B;から標準&#x200B;**背景**: 0 ～ 1\
  各インスタンスのマテリアルの法線がインスタンスの法線に与える影響を調整します。
* **法線角度ランダム**: 0 ～ 1\
  各インスタンスの法線をランダムな角度に傾斜させます。

**ラフネス**

* **ラフネス調整**: -1 ～ 1\
  ラフネスの値をインスタンス間で均一に増減
* **ラフネスランダム**: -1 ～ 1\
  各インスタンスのラフネスの値をランダムに増減
* **バックグラウンドからのラフネス**: 0 ～ 1\
  基礎となるマテリアルのラフネス値が各インスタンスのラフネス値に与える影響の度合いを調整します。

**Height**

* **Heightオフセット**: -1 ～ 1\
  インスタンスのHeightをオフセットします。 これは、インスタンスと基になるマテリアルのブレンド方法に影響を与える可能性があります。
* **Heightオフセットランダム**: 0 ～ 1\
  各インスタンスのHeightオフセットにランダム値を加えます
* **Heightスケール**: 0 ～ 2\
  すべてのインスタンスのHeightを調整します。
* **Heightスケールのランダム**: 0 ～ 1\
  各インスタンスのHeightにランダムな値を加える
* **Bg 勾配からの歪み**: 0-1\
  基になるマテリアルの勾配に合わせて、各インスタンスに勾配を追加します
* **バックグラウンド勾配 Smoothness**: 0 ～ 2\
  **Skew from Bg 勾配**&#x200B;パラメーターを使用するために、背景の勾配を調整します
* **背景に準拠**: 0-1\
  バックグラウンド高さマップがインスタンスの高さマップに与える影響を制御します。 これにより、背景のディテールに沿ってインスタンスを縮小できます
* **最適化された滑らかな背景**: 0 ～ 1\
  **背景に合わせる**&#x200B;による詳細の表示量を調整します

**メタリック**

* **メタリック調整**: -1から1\
  インスタンスのメタリック値の制御
* **メタリックランダム**: -1から1\
  各インスタンスのメタリック値に対してランダム値を増減
* **背景からメタリック**: 0 ～ 1\
  背景のメタリック値が各インスタンスにどの程度影響するかを調整

**マスク**

* **カスタムマスクを使用**：切り替え\
  これを有効にすると、カスタムマスクが使用され、カスタムマスクコントロールにアクセスできます。
  * **カスタムマスク**：画像/ブラシ\
    **2D ビュー**&#x200B;にカスタムマスクまたはペイントとして直接使用するイメージをインポートします
  * **カスタムマスクぼかし**: 0-1\
    カスタムマスクのエッジをぼかす
  * **カスタムマスクの反転**：切り替え
  * **カスタムマスクの不透明度**: 0 ～ 1\
    カスタムマスクの強さを調整する

使用方法ガイド

はねフィルターは、葉、石、ゴミ箱などのアセットをマテリアル全体で散乱化するのに便利な機能です。

スプラッタフィルタを使用するには：

1. スプラッターフィルターをレイヤースタックに追加する
1. スプラッタレイヤの下に入力スロットが表示されます
1. **基本パラメーター> マテリアル入力**&#x200B;で使用可能な入力スロット数をオプションで変更します
1. スプラッタ入力スロットにマテリアルをドラッグします

スプラッターレイヤーを選択すると、**プロパティパネル**&#x200B;で散乱パラメーターを調整できます。

**プロパティパネル**&#x200B;の入力マテリアルーのパラメーターを調整するには、入力スロットのマテリアルーをクリックします。
