## 説明

Atlas Scatterフィルターは、基本マテリアル全体で、アトラスマテリアル内の要素のインスタンスを散乱します。 Atlas Scatterは、葉や岩、ゴミなどを自然にマテリアルの上に散布するのに便利です。

次の図は、実行中の&#x200B;**Atlas Scatterフィルター**&#x200B;を示しています。

![](../../assets/3d-2d-filters-cropped-0037-atlas-scatter-in.jpg)

**Atlas Scatterフィルター**&#x200B;を使用する前に、基本的な泥材があります。あまりエキサイティングではありません。

![](../../assets/3d-2d-filters-cropped-0036-atlas-scatter-out.jpg)

小石アトラスで&#x200B;**Atlas Scatterフィルター**&#x200B;を加えると、小石が散らばり、下にある泥とリアルに混ざり合うため、マテリアルがさらに魅力的になります。

## パラメーター

**基本パラメーター**

* **X金額**: 1-64\
  X軸のインスタンス数
* **Y金額**: 1-64\
  Y軸のインスタンス数
* **描画モード**:\
  下のレイヤーとのブレンドに使用するメソッド
* **スケール**: 0 ～ 5\
  インスタンスのスケール
* **ランダムな位置**: 0 ～ 2\
  グリッド位置からのインスタンスのランダムオフセットを増減
* **Heightスケール**: 0 ～ 1\
  インスタンスのHeightを調整
* **背景に準拠**: 0-1\
  基になるHeightの値が散布インスタンスに与える影響を変化させる
* **背景の色**:
  * **色相：** 0-1\
    インスタンスの色相の調整
  * **彩度：** 0-1\
    インスタンスの彩度の調整
  * **値：** 0-1\
    インスタンスの値の調整

**マスク**

* **カスタムマスク**:トグル\
  カスタムマスクの使用を有効または無効にします。 有効にすると、次のコントロールが表示されます。
  * **カスタムマスク：**\
    マスクとして使用するファイルを選択するか、ブラシモードを使用して手動でマスクします。
  * **マスクの反転：**&#x200B;切り替え\
    マスクの値を反転
* **マスクのランダム**: 0 ～ 1\
  インスタンスの割合をランダムに非表示

**サイズ**

* **ランダムにスケール**: 0 ～ 1\
  各インスタンスに適用するランダム化されたスケールの量
* **スケール（重なりを除く）**: 0 ～ 1\
  インスタンスが重ならないように、各インスタンスのスケールを調整します

**Height**

* **Heightオフセット**: -1 ～ 1\
  基準レベル0からインスタンスのHeightをオフセット
* **Heightオフセットランダム**: 0 ～ 1\
  インスタンスごとにHeightオフセットにランダム値を加える
* **Bg 勾配からの歪み**: 0-1\
  背景の勾配に基づいて法線のゆがみを補正
* **バックグラウンドSmoothness**: 0 ～ 2\
  背景Smoothnessを調整

**回転**

* **回転**: 0 ～ 1\
  すべてのインスタンスを設定値で回転
* **ランダムな回転**: 0 ～ 1\
  インスタンスの回転にランダム値を追加する
* **Bg 勾配からの回転**:\
  基になるマテリアルの勾配に基づいてインスタンスを回転

**アトラスのマテリアル調整**

* **カラー調整**:\
  アトラスのHSV値を調整する
* **カラーランダム**:\
  **カラー調整**&#x200B;で設定されたHSV値にランダム度を追加します
* **背景からの粗さ** : 0 ～ 1\
  各インスタンスの粗さではなく、背景の粗さを使用します。
* **粗さの調整**: -1 ～ 1\
  各インスタンスの粗さの値を追加または削除します。
* **標準ランダム**: 0 ～ 1\
  インスタンスごとにランダム値で各インスタンスの法線を回転
* **アンビエントオクルージョンの再計算**：切り替え\
  オンに切り替えると、変更されたオクルージョン値に基づいて環境Height値が再計算されます

**アトラス図形の検出**

* **パターン範囲**:\
  位置に基づいて、アトラスから使用可能なアセットを制限します。 アトラスのすべてのアセットを使用するには、「X」と「Y」の値を0のままにします。
* **アトラスの不透明度をダウングレード**: 0 ～ 4
* **図形の検出精度**:\
  シェイプを検出するアルゴリズムを選択します。 異なるアトラスは、異なる検出アルゴリズムに適しています。 いずれの障害モードも、他のオプションよりも高い計算処理能力を必要としません。
* **次より小さい図形を無視**: 0-1\
  この機能を使用すると、非常に小さなシェイプを個別の要素として選択する必要がなくなります。

使用方法ガイド

Atlas Scatterフィルターは、葉、石、ゴミ箱などの素材のアセットを散乱化するのに便利です。 Atlas Scatterフィルターを使用するには、処理するフィルターのアトラスマテリアルが必要です。

>[!NOTE]
>
> アトラスマテリアルは、個別のアセットのコレクション（またはアトラス）を保持するマテリアルです。 例えば、Samplerにはデフォルトでドライローレルの葉が含まれています。これはアトラスマテリアルで、1つのマテリアル内で葉の集合が保持され、各葉が互いに独立しています。 Atlas Scatterノードは、アルゴリズムを使用して、アトラスマテリアルの各リーフを個別の要素として処理します。

Atlas Scatterフィルターを使用するには：

1. レイヤースタックへのAtlas Scatterフィルターの追加
1. Atlas Scatterレイヤーの下に、入力スロットが表示されます
1. アトラスマテリアルをAtlas Scatter入力スロットにドラッグします

散乱レイヤーを選択すると、**プロパティパネル**&#x200B;でAtlas Scatterパラメーターを調整できます。

入力スロットのマテリアルを選択すると、**プロパティパネル**&#x200B;でアトラスマテリアルのパラメーターを調整できます。
