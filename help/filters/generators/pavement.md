## パラメーター

**基本パラメーター**

* **ランダムシード**:\
  ランダムシードは、このフィルターのランダム度を使用する他のパラメーターのランダム値を決定します。
* **ベースマテリアルスケール**: 0 ～ 1\
  各レンガで使用するマテリアルの尺度をコントロールする
* **レンガの間隔**: 0 ～ 1\
  れんがの間隔を変更する
* **角の丸み**: 0 ～ 1\
  レンガの角の丸みを調整します。
* **エッジの丸み**: 0 ～ 1\
  レンガのエッジを滑らかにして、使い古したように見せます
* **ティルトの強度**: 0 ～ 1\
  各レンガに適用されるランダムな傾きの強度を変更
* **ランダムな高度の強度**: 0 ～ 1\
  互いに相対的なレンガのHeightのバリエーションを変更します。

**パターン**

各パターンには、**パターンの種類**&#x200B;でパターンを選択したときに表示される使用可能なパラメーターのセットが異なります。 様々なパラメーターを試して、効果を確認してください。

* **パターンの種類**:\
  れんがを置くパターンを選択します。

**ジョイント**

* **ジョイント** **Height**: 0 ～ 1\
  レンガ間のマテリアルのHeightを修正する
* **ジョイントの幅**: 0 ～ 1\
  レンガ間のマテリアルがレンガのエッジと重なる範囲を調整する
* **ジョイントの幅のバリエーション**: 0-1\
  **ジョイント幅**&#x200B;のランダム度を調整
* **関節輝度**: 0-1\
  レンガ間のマテリアルの外観を修正します。 これはマスクに便利です。

**詳細パラメーター**

* **表面の強度**: 0 ～ 1\
  亀裂やへこみなどのサーフェス変形の法線の強度を制御します。
* **表面サイズ(cm)**: 0 ～ 1000\
  マテリアルによって表される物理サイズを調整します
* **表面のHeightスケール(cm)**: 0 ～ 1000\
  Heightマップが表す物理空間を変更する
* **サーフェスSmoothness**: 0-1\
  サーフェスの変動と詳細の量をコントロールする
* **表面の突き**: 0-1\
  Heightと法線をランダムに変更して、サーフェスにダメージや変化を与える
* **表面ポークマスクのしきい値**: 0 ～ 1\
  **表面の突き**&#x200B;の制御に使用するマスクのしきい値を変更します
* **Scalemapを有効にする**:トグル\
  スケールマップを使用して、レンガの位置に基づいてレンガのサイズを調整します
* **Scalemapの強度**: 0-1\
  スケールマップがレンガのスケールに与える影響を調整します。
