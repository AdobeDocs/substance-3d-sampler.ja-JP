## パラメーター

**基本パラメーター**

* **エンボスサイズ**: 0 ～ 1\
  各インスタンスのサイズの変更
* **エンボスの距離**: 0 ～ 1\
  エンボスのThicknessを変更する
* **パターンの選択**:\
  エンボスに使用するパターンを選択します。 ここから、エンボステキストまたはカスタムパターンを選択できます。
* **パターンタイルX**: 1 ～ 64\
  X 軸上のインスタンス数を変更する
* **パターンタイルY**: 1 ～ 64\
  Y軸のインスタンス数を変更する

**エンボス**

* **境界線エンボスを使用**：切り替え\
  選択したパターンの境界線をエンボスするかどうかを切り替え
* **境界線エンボスの反転**：切り替え\
  境界線エンボスのHeightを反転
* **境界線のエンボス強度**: 0 ～ 1\
  エンボス効果の強さを変更する
* **塗りつぶしエンボスを使用**：切り替え\
  選択したパターンの塗りつぶしをエンボスするかどうかを切り替え
* **エンボスの入力反転**：切り替え\
  塗りつぶしエンボス効果のHeightを反転
* **塗りつぶしエンボスの適用度**: 0 ～ 1\
  エンボス効果の強さを変更する

**パターン**

* **色の使用**：切り替え\
  エンボス領域にカラーを追加するかどうかを選択\
  **カラーを使用**&#x200B;がオンになっている場合、追加の&#x200B;**カラー**&#x200B;パラメーターが表示され、カラーが調整されます。
* **パターンマスク** **距離**: 0 ～ 1\
  エンボス領域にカラーを適用するために使用するマスクのサイズを変更
* **パターンマスクのコントラスト**: 0-1\
  マスクのコントラストを調整します。 コントラストを下げると、マスクのエッジがぼやけて見えます。
* **パターンタイルを使用**：切り替え\
  オンに切り替えるとパターンが並べて表示され、オフに切り替えると1つのインスタンスのみが表示されます。 パターンが並べて表示されない場合、**[パターンタイル]**&#x200B;オプションは[**基本パラメーター**]セクションに表示されません。
* **パターンの回転**: 0 ～ 1\
  パターンを回転
* **パターンのオフセット**: 0 ～ 1\
  パターンの各行を前の行からオフセットします。
* **パターンラフネスを使用**：切り替え\
  これを有効にすると、エンボスエフェクトが表示される場所にかかわらず、基になるマテリアルのラフネスがカスタムのラフネス値で上書きされます。\
  有効にすると、**パターンラフネス**&#x200B;コントロールが表示され、ラフネスを設定できます。
* **パターンメタリックを使用**：切り替え\
  これを有効にすると、エンボスエフェクトが表示される場所にかかわらず、基になるマテリアルのメタリック値がカスタムのメタリック値で上書きされます。\
  有効にすると、**パターンメタリック**&#x200B;コントロールが表示され、ラフネスを設定できます。

**テキスト** – このセクションは、**基本パラメーター**&#x200B;の&#x200B;**パターン選択**&#x200B;が&#x200B;**テキスト**&#x200B;に設定されている場合にのみ表示されます

* **フォントの選択**:\
  書体を選択
* **テキスト**:テキストフィールド\
  エンボスするテキストを入力します
* **テキストサイズ**: 0 ～ 1\
  フォントサイズの調整

**消しゴム**

* **消しゴム法線**: 0 ～ 1
* **Ambient occlusion**: 0 ～ 1
* **消しゴムの不透明度**: 0 ～ 1

**詳細パラメーター**

これらのパラメーターを使用すると、マテリアル全体の値を調整できます。

* **輝度**: 0 ～ 1
* **コントラスト**: -1から1
* **色相のシフト**; 0 ～ 1
* **彩度**: 0 ～ 1
* **法線の強度**; 0 ～ 1

## 使用方法ガイド

レイヤースタックの上部にエンボスフィルターを追加し、パラメーターの調整を開始します。

最も重要なパラメーターは通常、**基本パラメーター>パターンの選択**&#x200B;で、フィルターで使用されるパターンを指定します。タイリングのオンとオフを切り替えるには、**パターン>パターンタイルを使用**&#x200B;です。
