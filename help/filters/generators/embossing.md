## パラメーター

**基本パラメーター**

* **エンボスサイズ**: 0 ～ 1\
  各インスタンスのサイズの変更
* **エンボス距離**: 0-1\
  エンボスのThicknessを変更する
* **パターンの選択**:\
  エンボスするパターンを選択します。 ここから、テキストまたはカスタムパターンをエンボスできます。
* **パターンタイルX**: 1 ～ 64\
  X軸上のインスタンス数を変更
* **パターンタイルY**: 1 ～ 64\
  Y軸上のインスタンス数を変更

**エンボス**

* **ボーダーエンボスを使用**：切り替え\
  選択したパターンの境界線をエンボスするかどうかを選択
* **境界線エンボスの反転**：切り替え\
  境界線のエンボスのHeightを反転
* **境界線エンボスの強さ**: 0 ～ 1\
  エンボス効果の強さを変更
* **塗りつぶしエンボスを使用**：切り替え\
  選択したパターンの塗りをエンボスするかどうかを切り替え
* **エンボスの塗りつぶしの反転**：切り替え\
  塗りつぶしエンボスエフェクトのHeightを反転
* **エンボスの強さ**: 0 ～ 1\
  エンボス効果の強さを変更

**パターン**

* **色の使用**：切り替え\
  エンボス領域にカラーを追加するかどうかを選択\
  **カラーを使用**&#x200B;がオンになっている場合、追加の&#x200B;**カラー**&#x200B;パラメーターが表示され、カラーが調整されます。
* **パターンマスク** **距離**: 0 ～ 1\
  エンボス領域にカラーを適用するために使用するマスクのサイズを変更
* **パターンマスクのコントラスト**: 0-1\
  マスクのコントラストを調整します。 コントラストを下げると、マスクのエッジがぼやけて見えます。
* **パターンタイルを使用**：切り替え\
  オンに切り替えるとパターンが並べて表示され、オフに切り替えると1つのインスタンスのみが表示されます。 パターンが並べて表示されない場合、**[パターンタイル]**&#x200B;オプションは[**基本パラメーター**]セクションに表示されません。
* **パターンの回転**: 0 ～ 1\
  パターンを回転
* **パターンのオフセット**: 0 ～ 1\
  パターンの各行を前の行からオフセットします。
* **パターンの粗さを使用**：切り替え\
  これを有効にすると、エンボス効果が現れる場所で、下になっているマテリアルの粗さがカスタムの粗さ値で上書きされます。\
  有効にすると、**パターンの粗さ**&#x200B;のコントロールが表示され、粗さが設定されます。
* **パターンのメタリックを使用**：切り替え\
  これを有効にすると、エンボスエフェクトが表示される場所にかかわらず、下にあるマテリアルのメタリック値がカスタムのメタリック値で上書きされます。\
  有効にすると、**パターンメタリック**&#x200B;のコントロールが表示され、粗さが設定されます。

**テキスト** – このセクションは、**基本パラメーター**&#x200B;の&#x200B;**パターン選択**&#x200B;が&#x200B;**テキスト**&#x200B;に設定されている場合にのみ表示されます

* **フォントの選択**:\
  書体を選択
* **テキスト**:テキストフィールド\
  エンボスするテキストを入力します
* **テキストサイズ**: 0 ～ 1\
  フォントサイズの調整

**消しゴム**

* **消しゴム法線**: 0 ～ 1
* **消しゴムのアンビエントオクルージョン**: 0-1
* **消しゴムの不透明度**: 0 ～ 1

**詳細パラメーター**

これらのパラメータを使用すると、マテリアル全体の値を調整できます。

* **輝度**: 0 ～ 1
* **コントラスト**: -1から1
* **色相のシフト**; 0 ～ 1
* **彩度**: 0 ～ 1
* **法線の強度**; 0 ～ 1

## 使用方法ガイド

レイヤースタックの一番上にエンボスフィルターを追加し、パラメーターの調整を開始します。

最も重要なパラメーターは通常、**基本パラメーター>パターンの選択**&#x200B;で、フィルターで使用されるパターンを変更します。また、**パターン>パターンタイルを使用**&#x200B;で、タイルのオンとオフを切り替えます。
