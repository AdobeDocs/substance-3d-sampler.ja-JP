## パラメーター

**基本パラメーター**

* **ランダムシード**:\
  このフィルタの他のすべてのランダムパラメータの基準となるランダムシード。
* **石のパターン**:\
  どのパターンを使用して石を配置するかを選択します
* **石の量**: 4-18\
  マテリアルを分割する石の数を調整します
* **石の丸み**: 0 ～ 1\
  石のエッジの損耗を制御する
* **石の平坦量**: 0 ～ 1\
  石と石間のモルタルの相対Heightを調整します
* **モルタルThickness**: 0 ～ 1\
  石の間のスペースを調整
* **モルタルHeight**: 0 ～ 1\
  石間のモルタルのHeightを増減する
* **モルタルの色**:カラー選択\
  石と石の間のモルタルの色を調整
* **汚れの量**: 0-1\
  マテリアルに適用される汚れとDirtの量を変更する
* **汚れの色**:カラーの選択\
  汚れのカラーを選択

**詳細パラメーター**

* **法線の強度**: 0 ～ 3\
  マテリアル全体の法線の強度をコントロールします。
