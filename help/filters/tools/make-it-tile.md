## 説明

**タイルフィルターを使用**&#x200B;して、マテリアルをタイル可能にします。 **タイル表示フィルター**&#x200B;を使用すると、マテリアルをタイル表示することもできますが、フィルターごとに動作が異なります。 **タイルフィルターを作成**&#x200B;が機能しない場合は、**タイルフィルター**&#x200B;を試してください。

次の画像では、**タイルフィルターを作成**&#x200B;して、タイルでないマテリアルをタイル可能なマテリアルに変換する方法を確認できます。 このマテリアルは、グリッドのようなパターンに沿っていて、焦点を引き付ける特定のポイントがないため、うまくタイル化されます。

![](../../assets/3d-2d-filters-cropped-0015-make-it-tile-in.jpg)

上の画像では、赤い線はマテリアルの境界を示しています。 強い継ぎ目があり、このマテリアルがタイル化しないことは明らかです。

![](../../assets/3d-2d-filters-cropped-0014-make-it-tile-out.jpg)

**タイルを作成**&#x200B;すると、このマテリアルは赤い線なしで十分にタイル化され、マテリアルの境界に継ぎ目が見えなくなります。

## パラメーター

**基本パラメーター**

* **しきい値**: 0 ～ 1\
  一番上のレイヤーのサイズとマッチングを調整します。
* **Smoothness**: 0 ～ 1\
  一番上のレイヤーの継ぎ目を滑らかにします。
* **コントラスト**: 0 ～ 1\
  継ぎ目のコントラストを調整します。 コントラストを下げても、継ぎ目をぼかしたときと同じように効果があります。
* **スポットの削除**：切り替え\
  有効にすると、フィルターは上下のレイヤー間の継ぎ目付近のアーティファクトを削除しようとします。
* **Color Equalizer**: 0 ～ 50\
  カラー値をイコライズして、継ぎ目を見やすくします。
* **Heightの一致**:\
  フィルターの上位レイヤーと下位レイヤーのHeightマップのブレンド方法を変更します。 結果をより明確に表示するには、**2Dビュー**&#x200B;でHeightチャンネルを表示します。 HeightマッチングはHeightチャンネル以外のチャンネルには影響しないので、法線とAOはHeightマッチングの変更の影響を受けません。

**詳細パラメーター**

* **クロミナンスの影響** : 0 ～ 1\
  継ぎ目に影響するカラー値を調整します。
* **マスクの反転**：切り替え\
  上下のレイヤーマスクを反転します。
* **Smoothnessに一致するHeight**: 0 ～ 16\
  上下のレイヤー間で一致するHeightのぼかしを調整します。
* **左/右パッチソース**: -1 ～ 1\
  左右のパッチのソースの場所を調整します。
* **パッチソースの上/下**: -1から1\
  上位および下位パッチのソースの場所を調整します。

## 使用方法ガイド

**タイルを作成** **フィルター**&#x200B;は、マテリアルの複数のコピーを重ね合わせることで機能します。

次の画像は、レイヤーのレイアウトを示しています。

* 緑の外周は、**タイルにする**&#x200B;フィルターの結果のマテリアルのエッジを示しています
* 赤い線は下のレイヤーの境界線を示します。 下のレイヤはX軸とY軸のUV空間の50%だけオフセットされているため、赤い線はカバーする必要があるタイリング継ぎ目です。
* 青い正方形と半円が赤い継ぎ目を覆っています。 フィルターのパラメーターを使用すると、青いシェイプの境界線を調整して、赤い継ぎ目が見えないようにしながら、青い継ぎ目をできる限り滑らかに保つことができます。

![](../../assets/makeittilediagram.png){width="512px"}

左右の半円が一致してマテリアルタイルが水平になるようにし、上下の半円がマテリアルタイルが垂直になるようにします。 中央の青い正方形は、残りのすべての縫い目を非表示にして、縫い目のない完全にタイル可能なマテリアルを作成します。
