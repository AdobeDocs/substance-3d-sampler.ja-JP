## 説明

**コピースタンプツール**&#x200B;を使用すると、マテリアルの一部を手動で複製したり、パッチを適用したりできます。 これは、継ぎ目を修正したり、マテリアルからエラーを削除する場合に便利です。**コピースタンプフィルター**&#x200B;は、左サイドバーで使用できるツールの1つです。

次の画像は、雪の材料から破片を取り除くために使用されている&#x200B;**コピースタンプ**&#x200B;を示しています。

![](../../assets/3d-2d-filters-cropped-0049-clone-stamp-in.jpg)

上の画像では、雪のマテリアルには多数の小枝やその他の破片が散らばっています。

![](../../assets/3d-2d-filters-cropped-0048-clone-stamp-out.jpg)

**コピースタンプ**&#x200B;ツールを使用して、小枝を除去し、きれいな雪に置き換えます。

## コピースタンプチュートリアル

## パラメーター

<b>基本パラメーター</b>

* <b>マスクを展開</b>: 0-1\
  塗りつぶされた領域の周囲で、フィルターが下になっているマテリアルと一致させる範囲を調整します。
* <b>ブレンドをフェード</b>: 0 ～ 1\
  クローン領域のエッジを柔らかくして、下にあるマテリアルとブレンドしやすくします。
* <b>ぼかしマスク</b>: 0-1\
  コピースタンプのエッジのディテール量を調整します。 この値を大きくすると、クローン領域のエッジが塗り潰しのようになります。
* <b>縦横比を維持</b>：切り替え\
  オフにすると、スタンプ領域の比率を調整できます。
  * <b>水平方向</b>: 0 ～ 2
  * <b>垂直方向</b>: 0 ～ 2
* <b>回転</b>: -180 ～ 180\
  スタンプ領域を回転します。
* <b>水平方向に反転</b>：切り替え\
  スタンプ領域を水平軸に沿ってミラーします。
* <b>垂直方向に反転</b>：切り替え\
  縦軸に沿ってスタンプ領域をミラーします。

<b>ブレンドをフェード</b>

フェードブレンドコントロールを使用して、マテリアルの各チャンネルのフェードブレンドを個別に調整します。

<b>詳細</b>

* <b>法線の強度</b>: 0 ～ 2\
  スタンプ領域の法線の強度を調整します。
* <b>ソースの位置</b>: \
  0-1：水平ソース位置を調整します。\
  0-1：ソースの垂直位置を調整します。
* <b>ターゲット位置</b>:\
  0-1：水平のターゲット位置を調整します。\
  0-1：垂直方向のターゲット位置を調整します。
* <b>タイルモード</b>:ドロップダウン\
  タイル表示を有効または無効にします。

## 使用方法ガイド

**コピースタンプツール**&#x200B;をクリックして、レイヤースタックの先頭に新しいコピースタンプフィルターレイヤーを作成します。 **レイヤーパネル**&#x200B;の&#x200B;**レイヤーを追加ボタン**&#x200B;を使用して、コピースタンプフィルターを追加することもできます。

コピースタンプフィルターレイヤーを作成すると、**2Dビュー**&#x200B;が&#x200B;**ビューポート**&#x200B;で自動的に開きます。 コピースタンプレイヤーを選択すると、**2Dビュー**&#x200B;の上部に&#x200B;**ツールバー**&#x200B;が表示されます。

![](../../assets/alchemist-2020-2-clone.gif){width="300px"}

コピースタンプツールの使用を開始するには、**2Dビュー**&#x200B;内の問題のある領域をクリックしてドラッグします。 材料はソースに基づいて自動的に更新されます。 **コピースタンプツール**&#x200B;を使用する領域がハイライト表示されます。

>[!NOTE]
>
> 他のビューポートツールバーと同様に、ツールバーの上部にあるハンドルをドラッグしてビューポート内にツールバーを再配置したり、ハンドルをダブルクリックして垂直モードと水平モードを切り替えたり、二重の山形を使用してツールバーを表示または非表示にしたりできます。

## ソースの選択

新しいソースを追加するには、2DビューでCtrlキーを押しながらクリックします。 新しいソースを追加すると、<b>レイヤーパネル</b>のコピースタンプレイヤーの下に追加スタンプが作成されます。 各スタンプを個別に制御できます。

>[!NOTE]
>
> 通常は、コピーする領域の近くにソースポイントを置かないようにすることをお勧めします。 ソースポイントが問題のある領域に近い場合は、問題のある領域をコピーできます。
