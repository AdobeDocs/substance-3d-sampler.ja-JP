## パラメーター

**基本パラメーター**

* **ランダムシード**:\
  ランダムシードは、このフィルターのランダム度を使用する他のパラメーターのランダム値を決定します。
* **ノイズの選択**:\
  ワープのベースにするノイズを選択します。 ノイズが異なると、様々な効果が生じる可能性があります。
* **ノイズスケール**: 0 ～ 10\
  ソースノイズのスケールを調整します。 ノイズは常に並べて表示されます。
* **型**:\
  マテリアルのワープに使用する方法を選択します。 **方向ワープ**&#x200B;または&#x200B;**多方向ワープ**&#x200B;を選択すると、追加のパラメーターが表示されます。
  * **ワープ角度**: 0-1\
    ワープの方向を調整する
* **強度**: 0 ～ 1\
  ワープの強さを調整します。
* **カスタムノイズ**:トグル\
  **[ノイズの選択]**&#x200B;で、選択範囲の代わりにカスタムノイズを使用できるようにします。 使用可能なパラメーターは、**カスタムノイズ**&#x200B;が有効か無効かに応じて変わります。 有効にすると、次のパラメーターが表示されます。
  * **カスタムノイズぼかし**: 0-1\
    カスタムノイズをぼかす
  * **カスタムノイズ**：画像/ブラシ\
    ワープソースとして使用するカスタムノイズマップを読み込みます。
* **チャンネルごとのワープ**：切り替え\
  有効にすると、追加のセクションが表示され、各チャンネルのワープを個別に制御できます。 各チャンネルには、次のパラメーターを使用できます。
  * ***チャネル名***：切り替え\
    このチャンネルに&#x200B;**ワープフィルター**&#x200B;の影響を与えるかどうかを切り替えます。
  * **描画モード**:\
    このチャンネルのワープ結果を下のレイヤーとブレンドする方法を選択します
  * **不透明度**: 0 ～ 1\
    このチャンネルのフィルター結果の不透明度を変更します。
