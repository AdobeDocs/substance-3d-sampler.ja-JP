# ツール

ツールはSamplerで最も大きなフィルターのセットであるため、ツールの特徴を理解するのが難しい場合があります。 ツールフィルターを理解する最も簡単な方法は、材料の技術的な問題を修正するために使用することです。

画像や素材に多くのツールを使用できます。 一般に、画像をマテリアルの一部に変換する前に、フィルターを使用して画像を補正することをお勧めします。 まず画像を補正することで、ツールは1つのチャンネルのみを処理するだけで済みます。画像データを補正する場合は、複数のチャンネルを補正する必要があります。 1つのチャネルを補正するだけで、必要な処理量が減少しますが、エラーの可能性も低下します。

ツールフィルターでは、**2Dビュー**&#x200B;のハンドルやその他のコントロールを使用している場合が多いので、ツールを使用しながら&#x200B;**2Dビュー**&#x200B;を表示することをお勧めします。
