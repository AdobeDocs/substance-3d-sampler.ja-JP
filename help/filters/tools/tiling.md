## 説明

**タイリングフィルター**&#x200B;を使用して、マテリアルを並べて表示できるようにします。 **タイルにするフィルター**&#x200B;を使用すると、マテリアルをタイル表示することもできますが、フィルターごとに動作が異なります。 **タイリングフィルター**&#x200B;が機能していない場合は、**タイルフィルターの作成**&#x200B;を試してください。

## パラメーター

**基本パラメーター**

* **シームの表示**：切り替え\
  シームを表示するかどうかを選ぶ
* **マスクを使用**：切り替え\
  有効にすると、カスタムマスクを作成して継ぎ目の位置を制御できます
  * **マスク**：画像/ブラシ\
    マスクとして使用する画像を読み込むか、ブラシを使用して&#x200B;**2D ビュー**&#x200B;内で直接マスクをペイントします

**エッジ**

* **エッジの検出**：切り替え\
  マテリアルレイヤー間をより有機的に変化させるために、マテリアルチャンネルに基づいてエッジを検出するかどうかを切り替えます。 有効にすると、次の追加パラメーターが表示されます。
  * **チャネルごとのしきい値を使用**：切り替え\
    有効にすると、追加のパラメーターが表示され、各チャンネルのしきい値が個別に調整されます。
    * **しきい値のBase color**: 0 ～ 1
    * **しきい値標準**: 0 ～ 1
    * **しきい値のHeight**: 0 ～ 1
  * **しきい値**: 0 ～ 1\
    シームを見つけるために使用するしきい値を調整します。
  * **ぼかし**: 0-1\
    継ぎ目の周囲のぼかし
  * **Smoothness**: 0 ～ 2\
    シームのSmoothnessを調整します。 これにより、アーティファクトを回避できます
  * **グリッドの解決**: 1 ～ 11\
    シームが描画されるグリッドの解像度を調整します。 解像度を下げると処理速度は向上しますが、シームの画質は低下します
  * **基本色を使用**：切り替え\
    シームの生成にbase color情報を考慮するかどうかを切り替える
  * **標準を使用**：切り替え\
    シームの生成に通常の情報を考慮するかどうかを切り替える
  * **Heightを使用**：切り替え\
    シームの生成にHeight情報を考慮するかどうかを切り替える
  * **切り取りオフセット**: 0 ～ 0.5\
    X軸とY軸の軸上でシームのオフセットを調整する

**詳細パラメーター**

* **変形**: 0 ～ 2\
  行列の変形値を調整します。 X値とW値を大きくして、下にあるピクセルと重なり合うマテリアルの間の重なりを調整します。
* **オフセット**: 0 ～ 1\
  x方向とY軸のマテリアルのオフセット
* **フィルタリング**:\
  サイズを変更するピクセルに対して使用するフィルタリング方式を選択します。 フィルタリングではピクセルがぼやけ、最も近いフィルタリングではピクセル間のハードエッジが維持されます。
* **入力サイズ**: 0-8192\
  入力のサイズをピクセル単位でXおよびY 軸上で調整します。

## 使用方法ガイド

**タイリングフィルター**&#x200B;は、次の2つの手順で機能します：

1. マテリアルをスケールおよびオフセットして、オーバーラップを生成します。
1. 次に、重なっているエッジを変化させて、継ぎ目を非表示にします。

したがって、**タイルフィルター**&#x200B;を使用するには、プロセスのこれらの2つの部分を調整すると、最適な結果を得ることができます。

1. **タイリングフィルター**&#x200B;をレイヤースタックの先頭に追加します
1. ハンドルを使用してマテリアルを変形し、シームを隠すのに十分なオーバーラップがあるようにします。
   1. マテリアルのスケーリングは、オーバーラップを作成するのに役立ちますが、ディテールが失われる可能性もあります。
1. **エッジ**&#x200B;セクションのパラメーターを調整して、シームを調整します。

一部のマテリアルでは、**タイリングフィルター**&#x200B;のみを使用しても、シームに沿って斑点や問題が発生することがあります。 この場合、**クローンスタンプ**&#x200B;などの他のフィルターを使用して、シームやタイリングの問題を解決することをお勧めします。

マテリアルの作成処理の早い段階で、マテリアルのタイリングを行うことをお勧めします。タイリング以外の要素がマテリアルに追加されるとすぐに、作業を進める前に要素を並べて表示することをお勧めします。 Samplerフィルターは、タイリングするマテリアルを壊さないように設計されています。 つまり、基礎となるマテリアルがタイル化されても、フィルターとSamplerに含まれるマテリアルの操作を続行でき、マテリアルはタイル化されます。
