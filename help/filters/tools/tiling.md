## 説明

**タイルフィルター**&#x200B;を使用して、マテリアルをタイル可能にします。 **タイルにするフィルター**&#x200B;を使用すると、マテリアルもタイル可能になりますが、フィルターごとに動作が異なります。 **タイルフィルター**&#x200B;が機能していない場合は、**タイルフィルターを作成**&#x200B;してみてください。

## パラメーター

**基本パラメーター**

* **縫い目を表示**：切り替え\
  継ぎ目を表示するかどうかを選択
* **マスクを使用**：切り替え\
  有効にすると、カスタムマスクを作成して継ぎ目の位置を制御できます
  * **マスク**：画像/ブラシ\
    マスクとして使用する画像を読み込むか、ブラシを使用して&#x200B;**2Dビュー**&#x200B;で直接マスクをペイントします

**エッジ**

* **エッジの検出**：切り替え\
  マテリアルレイヤー間をより有機的に遷移させるために、マテリアルチャンネルに基づいてエッジを検出するかどうかを切り替えます。 有効にすると、次の追加パラメーターが表示されます。
  * **チャネルごとのしきい値を使用**：切り替え\
    有効にすると、追加のパラメーターが表示され、各チャンネルのしきい値が個別に調整されます。
    * **しきい値の基本色**: 0-1
    * **しきい値標準**: 0 ～ 1
    * **しきい値のHeight**: 0 ～ 1
  * **しきい値**: 0 ～ 1\
    継ぎ目の検索に使用するスレッショルド値を調整します。
  * **ぼかし**: 0-1\
    継ぎ目の周囲のぼかし
  * **Smoothness**: 0 ～ 2\
    継ぎ目のSmoothnessを調整します。 これにより、アーティファクトを回避できます
  * **グリッドの解像度**: 1 ～ 11\
    継ぎ目が描画されるグリッドの解像度を調整します。 解像度を低くするとパフォーマンスは向上しますが、継ぎ目の品質は低下します
  * **基本色を使用**：切り替え\
    シームの生成に基本カラー情報を考慮するかどうかを切り替える
  * **標準を使用**：切り替え\
    シームの生成に通常の情報を考慮するかどうかを切り替える
  * **Heightを使用**：切り替え\
    シーム生成でHeight情報を考慮するかどうかを切り替える
  * **切り取りオフセット**: 0 ～ 0.5\
    X軸とY軸での継ぎ目のオフセットを調整

**詳細パラメーター**

* **変換**: 0 ～ 2\
  行列の変形値を調整します。 X値とW値を大きくして、下にあるマテリアルと重なっているマテリアルの間の重なりを調整します。
* **オフセット**: 0 ～ 1\
  x軸とY軸でのマテリアルのオフセット
* **フィルター**:\
  サイズを変更したピクセルに対して使用するフィルター方法を選択します。 バイリニアフィルターではピクセルがぼかされますが、最も近いフィルターではピクセル間のハードエッジが維持されます。
* **入力サイズ**: 0-8192\
  入力のサイズをX軸とY軸のピクセル単位で調整します。

## 使用方法ガイド

**タイルフィルター**&#x200B;は、次の2つの手順で機能します。

1. これにより、マテリアルがスケールされ、オフセットされて、オーバーラップが生成されます。
1. 次に、重なっているエッジを変化させて、継ぎ目を非表示にします。

したがって、**タイルフィルター**&#x200B;を使用するには、プロセスのこれらの2つの部分を調整すると、最適な結果を得ることができます。

1. **タイルフィルター**&#x200B;をレイヤースタックの先頭に追加します
1. ハンドルを使用してマテリアルを変換し、継ぎ目を非表示にするのに十分なオーバーラップを作成します。
   1. マテリアルの尺度を変更すると、重なりを作成するのに役立ちますが、詳細が失われる場合があります。
1. **エッジ**&#x200B;セクションのパラメーターを調整して、縫い目を調整します。

一部のマテリアルでは、**タイリングフィルター**&#x200B;のみを使用しても、継ぎ目に沿ってアーティファクトや問題が発生することがあります。 この場合、**コピースタンプ**&#x200B;などの他のフィルターを使用して、継ぎ目やタイリングの問題を修正することをお勧めします。

マテリアルの作成プロセスの早い段階で、マテリアルをタイル表示することをお勧めします。タイル表示をしない要素がマテリアルに追加されるとすぐに、作業を進める前に必ずタイル表示にすることをお勧めします。 Samplerフィルターは、タイリングするマテリアルを壊さないように設計されています。 つまり、基本のマテリアルタイルが表示されたら、フィルターやSamplerに含まれるマテリアルの操作を続行でき、マテリアルはタイル表示されます。
