## 説明

環境光のパッチの問題領域。 パノラマパッチは、変形と傾斜を維持して、パッチを背景サーフェスに自然に一致させます。

次の画像は、<b>パノラマパッチ</b>の動作を示しています。この場合は、大きな雲の中心が空に置き換えられます。

## パラメーター

**基本パラメーター**

* **パッチの半径**: 0 ～ 1\
  パッチのサイズを調整します。
* **パッチのコントラスト：** 0-1\
  パッチのエッジの硬さを調整します。
* **パッチの回転**: 0 ～ 1\
  パッチが適用された領域を回転します。

## 使用方法ガイド

**パノラマパッチフィルター**&#x200B;をレイヤースタックの一番上に追加し、**2Dビュー**&#x200B;のハンドルを使用してソースとパッチの場所を調整します。
