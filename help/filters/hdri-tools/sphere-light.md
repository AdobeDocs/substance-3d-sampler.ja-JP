## パラメーター

**基本パラメーター**

* **図形のカラーモード**:\
  ライトのカラーの決定に使用する方法を選択します。 使用可能なパラメーターは、この選択に基づいて変更されます。
  * **温度（ケルビン）**
    * **温度**: 1000 ～ 27000\
      ライトの温度を調整します。
  * **RGB**
    * **色**：色の選択\
      ライトのカラーを選択します。
  * **画像の入力**
    * **シェイプ画像の入力**：画像/ブラシ\
      カラーとして使用する画像を読み込みます。 ブラシツールを使用して&#x200B;**2Dビュー**&#x200B;で直接ペイントすることもできますが、このフィルターでは予測できない結果が生じる可能性があります。
  * **サンプルの背景**
    * 背景サンプルを使用しても、新しいパラメーターは使用できません。代わりに、背景色に基づいて明るいカラーが設定されます。
* **露光量(EV)**: 0 ～ 10\
  ライトの露光量または明るさを調整します。
* **球の半径**: 0 ～ 1\
  ライトのサイズを調整します。
* **位置モード**:\
  ライトの位置の決定に使用する方法を変更します。 **位置座標**&#x200B;セクションのパラメーターは、選択に基づいて変更されます。

**位置の座標**

使用できるパラメーターは、**基本パラメーター/位置モード**&#x200B;で選択したパラメーターによって異なります。 **原点**&#x200B;が選択されている場合は、次のパラメーターを使用できます：

* **原点**: 0 ～ 20\
  カメラからの光の距離を調整します。
* **カメラの位置**: 0 ～ 1\
  X、Y、Z軸のライトに対するカメラの相対位置を調整します。

**ワールド位置**&#x200B;が選択されている場合、次のパラメーターを使用できます：

* **上向きベクター**:\
  上の方向を変更します。
* **球のワールド位置**: -2 ～ 2\
  X軸、Y軸、Z軸の球体光の位置を調整します。
* **原点**: 0 ～ 20\
  カメラからの光の距離を調整します。
* **カメラの位置**: 0 ～ 1\
  X、Y、Z軸のライトに対するカメラの相対位置を調整します。

**図形**

* **球の硬さ**: 0 ～ 1\
  球体光のエッジをソフトにしたり、強くしたりします
* **シェーディング**:\
  様々なスタイルの現実世界の光に基づいて、光の露光量のグラデーションを変更します。 **シェーディング光**&#x200B;を選択すると、次のパラメーターが表示されます。
  * **シェーディング照明のワールド位置**: -1 ～ 1\
    ライト上のシェーディングされた領域の位置を修正する
  * **Penumbra透明度**: 0 ～ 1\
    ライトのシェーディングされた領域の不透明度のレベルを調整します。

**背景**

* **バックグラウンドガンマ**:\
  背景ガンマの決定に使用するカラーシステムを選択します。
