## パラメーター

**基本パラメーター**

* **露光量(EV)**: 0 ～ 10\
  ライトの露光量または明るさを調整します。
* **図形のカラーモード**:\
  ライトのカラーの決定に使用する方法を選択します。 使用可能なパラメーターは、この選択に基づいて変更されます。
  * **温度（ケルビン）**
    * **温度**: 1000 ～ 27000\
      ライトの温度を調整します。
  * **RGB**
    * **色**：色の選択\
      ライトのカラーを選択します。
  * **画像の入力**
    * **シェイプ画像の入力**：画像/ブラシ\
      カラーとして使用する画像を読み込みます。 ブラシツールを使用して&#x200B;**2Dビュー**&#x200B;で直接ペイントすることもできますが、このフィルターでは予測できない結果が生じる可能性があります。
  * **サンプルの背景**
    * 背景サンプルを使用しても、新しいパラメーターは使用できません。代わりに、背景色に基づいて明るいカラーが設定されます。
* **位置モード**:\
  ライトの位置の決定に使用する方法を変更します。 **位置座標**&#x200B;セクションのパラメーターは、選択に基づいて変更されます。 **ワールド位置**&#x200B;を選択すると、ハンドルが&#x200B;**2Dビュー**&#x200B;から消えます。代わりに&#x200B;**位置座標**&#x200B;のパラメーターを使用して、ライトの位置を変更します。

**図形**

* **平面スケール**; 0 ～ 1\
  ライトのスケールを調整します。
* **平面サイズ**: 0 ～ 1\
  ライトのX軸とY軸の寸法を調整します。
* **面の回転**: 0 ～ 1\
  X、Y、Z軸方向のライトの回転を調整します。
* **パターン**:\
  ライトのシェイプを選択します。
* **パターンの硬さ**: 0 ～ 1\
  ライトのエッジをソフトにしたり、ぼかしたりする
* **パターンUVモード**:\
  エッジとコーナーのディテールを保持するために、変形をシェイプ全体にストレッチするか、シェイプの中央のみにストレッチするかを選択します。

**位置の座標**

使用できるパラメーターは、**基本パラメーター/位置モード**&#x200B;で選択したパラメーターによって異なります。 **地面/天井**&#x200B;または&#x200B;**原点**&#x200B;が選択されている場合は、次のパラメーターを使用できます：

* **行の絶対Height**: 0-1\
  カメラからの光の距離を変更します。
* **カメラの位置**: 0 ～ 1\
  X、Y、Z軸のライトに対するカメラの相対位置を調整します。

**ワールド位置**&#x200B;が&#x200B;**基本パラメーター>ポジションモード**&#x200B;で選択されている場合、次のパラメーターを使用できます：

* **上向きベクター**:\
  上の方向を変更します。
* **ポイント1ワールド位置**: -2 ～ 2\
  X、Y、Z軸の線の最初の点の位置を調整します。
* **ポイント2ワールド位置**: -2 ～ 2\
  X、Y、Z軸の線の2番目の点の位置を調整します。
* **カメラの位置**: 0 ～ 1\
  X、Y、Z軸のライトに対するカメラの相対位置を調整します。

**背景**

* **グリッドの表示**：切り替え\
  グリッドの表示と非表示を切り替えます。
* **グラウンドクリッピングを有効にする**：切り替え\
  光が地面を通過できるかどうかを選択します。 有効にすると、次のコントロールが表示されます。
  * **地面のHeight**: -2 ～ 2\
    光をクリッピングするために、地面のHeightを調整します。
* **バックグラウンドガンマ**:\
  背景ガンマの決定に使用するカラーシステムを選択します。
