# HDRI ツール

>[!IMPORTANT]
>
> 将来の変更
> 
> 環境光とメッシュのサポートは、Sampler V5.2のリリースで削除される予定です。 環境光の除去には、HDRI ツールとフィルターの除去も含まれます。

「HDRI ツール」セクションのフィルターは、特に環境光を操作するためのツールです。 HDRIはハイダイナミックレンジ画像の略ですが、環境光を作り出すために使用されるパノラマ画像を指す場合によく使用されます。 従来のソフトウェアでは、球面3Dデータを2Dイメージファイルにマッピングする必要があるため、パノラマ画像の修正は困難な場合があります。SamplerのHDRI ツールは、このような点を考慮して設計されているため、HDRIにパッチを適用してライトを追加する作業が非常に簡単です。
