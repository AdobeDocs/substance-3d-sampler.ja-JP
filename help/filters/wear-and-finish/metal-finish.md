## 説明

マテリアルを、多くの仕上げとスタイルを持つ金属に変換します。

***金属仕上げフィルター***を使用して、金属原料をブラシ加工された金属表面に変換します。

## パラメーター

**基本パラメーター**

* **ランダムシード**:\
  ランダムシードは、このフィルターのランダム度を使用する他のパラメーターのランダム値を決定します。
* **メタリックのみを変更**：切り替え\
  有効にすると、このフィルターはメタリックチャンネルへの変更を制限します。
* **メタルカラーモード**:\
  既存の金属に基づいてカラーを選択するか、独自のカラーを選択します。 **カスタムカラー**&#x200B;を選択すると、次のコントロールが表示されます。
  * **メタルの色**:カラー選択\
    金属仕上げのカスタムカラーを選択します。
* **種類の終了**:\
  金属に適用するスタイルを選択します。 スタイルごとに異なるパラメーターがあり、スタイルの外観を調整できます。 次のパラメーターが表示されます。
  * **強度**: 0 ～ 1\
    選択した仕上げの強度を調整します。
  * **スケール**: 0 ～ 1\
    選択した仕上げを駆動するパターンの尺度を修正します。
  * **粗さ** : 0 ～ 1\
    金属の粗さの値を制御します。
  * **ビーズスケール**: 0 ～ 1\
    **サンドブラスト**&#x200B;で利用可能です。 サンドブラスト効果の作成に使用するビーズのサイズを設定します。
  * **研磨**: 0 ～ 1\
    **キャスト**&#x200B;で利用可能です。 材料の高い部分を滑らかにする研磨量を調整します。
  * **パターン**:\
    **Grinded**&#x200B;で利用可能です。 グラインダーが使用するパターンを設定します。
  * **リリーフの詳細**: 0-1\
    **Raw**&#x200B;で利用可能です。 法線の強度を調整します。
  * **方向**: 0-1\
    利用可能： **ブラシ仕上げ** ブラシ効果の方向を変更します。
  * **ブラシの長さ**: 0 ～ 1\
    利用可能： **ブラシ仕上げ** ブラシ効果の作成に使用するストロークの長さを変更します。
  * **ブラシ**: 0-1\
    **亜鉛メッキ**&#x200B;で使用可能です。 亜鉛メッキ仕上げにブラシ仕上げの外観をオーバーレイします。

**マスク**

* **カスタムマスクを使用**：切り替え\
  カスタムマスクの使用を有効または無効にします。 有効にすると、次のパラメーターが表示されます。
  * **マスク**：画像/ブラシ\
    マスクとして使用する画像を選択するか、ブラシを使用して2Dビューでカスタムマスクを直接ペイントします。
  * **カスタムマスク – ぼかし**: 0-1\
    マスクをぼかします。
  * **カスタムマスク – 反転**：切り替え\
    マスクを反転します。

**詳細パラメーター**

* **基本色**：切り替え\
  ベースカラーチャンネルにフィルターを適用するかどうかを設定します。
* **メタリック**：切り替え\
  メタリックチャンネルがフィルターの影響を受けるかどうかを設定します。
* **粗さ**：切り替え\
  粗さチャンネルがフィルターの影響を受けるかどうかを設定します。
* **Specular level**:トグル\
  Specular levelチャンネルがフィルターの影響を受けるかどうかを制御します。 有効にすると、追加のコントロールが表示されます。
  * **Specular level** **– 値**: 0-1\
    Specularチャンネルの値を調整します。

>[!NOTE]
>
> 現在、**Specular level**&#x200B;コントロールを無効にした場合、再度有効にするコントロールがないと、そのコントロールが消える可能性がある既知のバグがあります。 **Specular level**&#x200B;コントロールを失ったものの、元に戻す必要がある場合は、「取り消し」（macOSのCtrl + zまたはCmd + z）を使用して、切り替えスイッチを無効にした状態を取り消すことができます。

* **標準**：切り替え\
  法線チャンネルがフィルタの影響を受けるかどうかを設定します。 有効にすると、追加のコントロールが表示されます。
  * **法線の強度**: 0 ～ 1\
    フィルターを使用して、通常の編集の強度を調整します。
* **Height**:トグル\
  Heightチャンネルがフィルターの影響を受けるかどうかを設定します。
* **放射性**：切り替え\
  放射チャンネルがフィルターの影響を受けるかどうかを設定します。 有効にすると、追加のコントロールが表示されます。
  * **放射型 – カラー**:カラー選択\
    放射チャンネルのカラーを設定します。
* **環境オクルージョン**：切り替え\
  周囲のオクルージョンチャンネルがフィルターの影響を受けるかどうかを設定します。 有効にすると、次の追加コントロールが表示されます。
  * **周囲オクルージョン – 強度**: 0-1\
    生成されたAOの強度を調整します。
  * **環境オクルージョン** **– 半径**: 0-1\
    AO効果の半径を調整します。
* **不透明度**：切り替え\
  不透明度チャンネルにフィルターを適用するかどうかを設定します。 有効にすると、追加のコントロールが表示されます。
  * **不透明度 – 値**: 0 ～ 1\
    マテリアルの不透明度を変更します。
