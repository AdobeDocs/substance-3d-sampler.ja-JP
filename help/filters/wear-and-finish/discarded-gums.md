## パラメーター

**基本パラメーター**

* **ランダムシード**:\
  ランダムシードは、このフィルターのランダム度を使用する他のパラメーターのランダム値を決定します。
* **ガムの密度**: 0 ～ 1\
  スポットの表示数を調整します。
* **ガムサイズ**: 0 ～ 1\
  スポットのスケールを調整します。
* **ガムの色1**:カラー選択。\
  スポットのカラーを変更します。
* **ガムの色2** :カラー選択\
  スポットのカラーを変更します。
* **ガムの色分布バランス**: 0-1\
  各カラーのアピアランスの相対頻度を調整します。
* **ガムの経年劣化**: 0 ～ 1\
  斑点の外観を変更して、年を取ったり若く見えるようにします。 この値を0に設定すると、**ガムの経年変化**&#x200B;スライダーが消えます。
* **ガムの経年変化**: 0-1\
  斑点の年齢をランダムに変化させる
* **ゴムの老化減光**: 0-1\
  経年変化でスポットが暗くなる量を調整します。
* **ガムのDirt**: 0 ～ 1\
  スポットの汚れの表示方法を制御します。
* **ガムのDirtの色**:カラーの選択\
  スポットに重ねるDirtのカラーを選択します。
* **ガムのDirtバリエーション**:\
  スポット間でDirtが変化する度合いを調整します。
* **カスタムマスク**:トグル\
  カスタムマスクの使用を有効または無効にします。 **カスタムマスク**&#x200B;が有効になっている場合、次のコントロールが表示されます：
  * **マスク**：画像/ブラシ\
    マスクとして使用する画像を選択するか、ブラシを使用して2Dビューでカスタムマスクを直接ペイントします。

**詳細パラメーター**

* **歯肉のHeight範囲**: 0 ～ 1\
  スポットが下のサーフェス上に広がる範囲をコントロールします。
* **歯肉の標準強度**: 0 ～ 1\
  スポットによる通常の衝撃の強度を調整します。
