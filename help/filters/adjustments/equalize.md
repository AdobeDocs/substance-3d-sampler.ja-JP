## 説明

イコライザーフィルターは、距離の範囲に基づいて部分的なコントラストを調整します。 イコライザーフィルターの目的は、各チャンネルの大きな差を少なくすることです。 一般的に、このフィルターは画像からマテリアル(B2M)へのワークフローの一部として役立ちます。画像からマテリアル（AI搭載）フィルターには、結果を改善するためのイコライズパスがフィルター内に含まれています。

下の画像は、**イコライズフィルター**&#x200B;の動作を示しています。

![](../../assets/3d-2d-filters-cropped-0033-equalizer-in.jpg)

**平均化フィルター**&#x200B;が追加される前は、このマテリアルのHeightマップと基本色に大きなばらつきがあります。

![](../../assets/3d-2d-filters-cropped-0032-equalizer-out.jpg)

**イコライザーフィルター**&#x200B;を追加すると、詳細を損なうことなく、Heightマップとベースカラーチャンネルがより均一になります。

## 平均化フィルターのチュートリアル

## パラメーター

<b>基本パラメーター</b>

* <b>タイリングされた入力</b>：切り替え\
  有効にすると、マテリアルが繰り返しタイリングされているかのように扱われるため、境界の近くで変更すると、反対側の境界のカラー値の影響を受けます。
* <b>半径</b>: 0 ～ 1\
  イコライザーエフェクトを広い領域に適用します。
* <b>色のにじみ</b>: 0 ～ 1\
  周囲の領域に裁ち落とすカラーを制御します。
* <b>ローカルの詳細</b>: 0-1\
  イコライズフィルターで部分的なディテールを保持する方法を調整します。

<b>*チャネル*</b>

各チャンネルのコントロールは同じように機能します。

* <b>共通パラメーターの上書き</b>：切り替え\
  これを有効にすると、このチャンネルのイコライズエフェクトがカスタマイズされます。 有効にすると、追加のコントロールが表示されます。
  * <b>タイリングされた入力</b>：切り替え\
    有効にすると、マテリアルが繰り返しタイリングされているかのように扱われるため、境界の近くで変更すると、反対側の境界のカラー値の影響を受けます。
  * <b>半径</b>: 0 ～ 1\
    イコライザー効果をより広い範囲に適用します。
  * <b>地域の違いを維持</b>：切り替え\
    イコライザーエフェクトを高解像度で使用して、ディテールを維持します
* <b>ターゲットモード</b>:\
  イコライズエフェクトをバイアスする方法を選択します。 初期設定では、「平均化（イコライズ）」はチャンネルの平均色に向かってカラーを移動しようとします。 代わりに、選択したカラーまたは値にバイアスするには、[パラメータ]を使用します。 「パラメーター」を選択すると、追加のコントロールが表示されます。
  * <b>ターゲット</b>:カラー選択\
    イコライズアルゴリズムの対象にするカラーまたは値を選択します。
* <b>カスタムカラーバリエーション</b> : HSLスライダー\
  指定したチャンネルに対してイコライズアルゴリズムを実行した後で、結果の色相、クロマ（彩度）、明度（輝度）を調整します。

<b>マスク</b>

* <b>カスタムマスク</b>:トグル\
  このフィルターのカスタムマスクの使用を有効または無効にする
* <b>カスタムマスク</b>：画像/ブラシ\
  マスクとして使用する画像を選択するか、ブラシを使用して2Dビューでカスタムマスクを直接ペイントします
* <b>カスタムマスクの反転</b>：切り替え
