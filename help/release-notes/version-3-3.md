# バージョン3.3

**Substance 3D Sampler 3.3.0**&#x200B;では、マテリアルや環境光をより簡単に作成および編集できる一連の新しいツール、コンテンツ、および機能が導入されています。

*リリース日： 2022年5月17日*

## 主な機能

## コンテンツに応じた塗りつぶし

コンテンツに応じた塗りつぶしは、Adobe Photoshopでよく使用されている機能です。周囲の領域の整合性を保ちながら、写真のディテールを除去します。

Substance 3D Samplerでは、これと同じテクノロジーを使用して、PBR マテリアルと環境光をクリーンアップできるようになりました。 PBR マテリアルでは、コンテンツに応じた塗りつぶしがすべてのチャンネルに適用されます。 各チャンネルを個別に処理する必要はありません。

コンテンツに応じた塗りつぶしは、マテリアルをタイリングするときに繰り返しを避けるために、またはスキャンしたファブリック上の小さな問題点を取り除くために、大きな要素を取り除くのに役立ちます。

360度パノラマを撮影する場合、シーン内のすべての要素を制御できるとは限らないため、地面にある小さなオブジェクト、壁の絵画、または背景に立っている人物を取り除く必要があります。 コンテンツに応じた塗りつぶしにより、これが容易になりました。

## IBLオーサリング

### 球面投影法

環境光と360枚の画像を通常の画像として表示すると、編集が困難になる場合があります。 すべての要素が歪んでおり、編集がほとんど不可能です。 この新しい球面投影法では、360度移動して、Nadir Patch、コンテンツに応じた塗りつぶし、ゆがみなしのすべてのプロシージャル照明などの専用ツールで編集できます。 例えば、直線の編集や清掃、カメラの三脚の取り外し、ラインライトの完全な配置などが簡単になりました。

新しいチュートリアルをチェックして、この新しいモードを使用して[環境光を作成](https://www.youtube.com/watch?v=cfW9IyoTXQ8)します。

### 露光量スライダー

2D ビューでは、露光量を一時的に変更して、編集中の環境の露出不足の部分や露出過多の部分のディテールまたはオブジェクトを確認しやすくすることができます。

### 専用ビューアの設定

ビューアの設定は、アセットの種類（マテリアルまたは環境光）ごとに永続的です。 各アセットタイプのメッシュ、デフォルトテクスチャ、カメラ視野を設定して、適切なコンテキストで動作するように切り替えることができます。

## ウィジェットの改善

### クローンスタンプ

このクローンスタンプの更新を使用すると、様々なソースを持つ複数のスタンプストロークを1つのレイヤーでペイントし、レイヤースタックのスタンプ履歴にアクセスできます。 また、ペイントする前に、ブラシプレビューでスタンプ結果を直接確認できるようになりました。 これにより、マテリアルのクリーニングが容易になり、ビュー間で何度も行き来する必要がなくなります。

### 切り抜きと変形

このアップデートでは、ウィジェットの切り抜きと変形の操作に新しいショートカットが導入されています。

### ブラシツールバー

新しいUIは、ツールバーなどの最新のAdobe製品に似ており、Frescoを2D ビュー内の任意の場所に、縦または横に表示して動かすことができます。 ペイント中にEキーを押してブラシと消しゴムを切り替え、新しいタイリングオプションを使用して、ペイントするオブジェクトをより適切に制御します。

## 画像からマテリアルへ（AI搭載）

### タイリングを保持

「画像をマテリアルに変換（AI搭載）」が新たな選択肢となります。タイル化可能な画像のタイリングを保持できるため、後でマテリアルをタイル化する時間が短縮されます。

## 互換性

Stagerにマテリアルを送信

Stagerに環境光を送ることはすでに可能でした。 DesignerやPainterと同様に、ワンクリックでマテリアルをStagerに送信できるようになりました。 この機能により、マテリアルを公開し、個別のファイルとしてStagerに読み込む必要がなくなりました（新しいマテリアルマネージャーを備えたStagerバージョン1.2.0が必要です）。
