# バージョン3.3

**Substance 3D Sampler 3.3.0**&#x200B;では、マテリアルや環境光をより簡単に作成および編集できる一連の新しいツール、コンテンツ、および機能が導入されています。

*リリース日： 2022年5月17日*

## 主な機能

## コンテンツに応じた塗りつぶし

コンテンツに応じた塗りつぶしは、Adobe Photoshopでよく使用されている機能です。周囲の領域の整合性を保ちながら、写真のディテールを除去します。

Substance 3D Samplerでは、これと同じテクノロジーを使用して、PBRマテリアルと環境光のクリーニングができるようになりました。 PBRマテリアルでは、コンテンツに応じた塗りつぶしがすべてのチャンネルに適用されます。 各チャンネルを個別に処理する必要はありません。

コンテンツに応じた塗りつぶしは、素材をタイリングする際に繰り返しを避けるために、大きな要素を削除したり、スキャンしたファブリックの小さな問題点を削除したりするのに役立ちます。

360度パノラマを撮影すると、シーン内のすべての要素を制御できなくなる場合があります。このため、地面にある小さなオブジェクト、壁の絵、または背景に立っている人物を削除する必要があります。 コンテンツに応じた塗りつぶしにより、これが容易になりました。

## IBLオーサリング

### 球面投影法

環境光と360枚の画像を通常の画像として表示すると、編集が困難になる場合があります。 すべての要素が歪んでおり、編集がほとんど不可能です。 新しい球面投影法では、360度で移動し、Nadir Patch、コンテンツに応じた塗りつぶし、ゆがみなしのすべての手続き型ライトなどの専用ツールを使って編集できます。 例えば、直線の編集や清掃、カメラの三脚の取り外し、ラインライトの完全な配置などが簡単になりました。

この新しいモードを使用して[環境光の作成](https://www.youtube.com/watch?v=cfW9IyoTXQ8)を行う新しいチュートリアルを確認してください。

### 露光量スライダー

2Dビューでは、編集中の環境の露出不足または露出過多の部分のディテールまたはオブジェクトがよく見えるように、露光量を一時的に変更できます。

### 専用ビューアの設定

ビューアの設定は、アセットの種類（マテリアルまたは環境光）ごとに永続的です。 各アセットタイプのメッシュ、デフォルトのテクスチャ、またはカメラの視野を設定して、適切なコンテキストで動作するように切り替えることができます。

## ウィジェットの改善

### コピースタンプ

このコピースタンプの更新を使用すると、様々なソースを持つ複数のスタンプストロークを1つのレイヤーにペイントし、レイヤースタックのスタンプ履歴にアクセスできます。 また、ペイントする前に、ブラシプレビューでスタンプ結果を直接確認できるようになりました。 これにより、マテリアルのクリーニングが容易になり、ビュー間で何度も行き来する必要がなくなります。

### 切り抜きと変形

このアップデートでは、切り抜きと変形ウィジェットの操作に新しいショートカットが導入されています。

### ブラシツールバー

Frescoなどの最新のAdobe製品に似た新しいUIを使用すると、2Dビュー内の任意の場所に、垂直または水平方向にツールバーを移動できます。 ペイント中にEキーを押してブラシと消しゴムを切り替え、新しいタイリングオプションを使用して、ペイントする対象をより適切に制御します。

## 画像からマテリアル（AI搭載）

### タイルを保持

画像からマテリアル（AI搭載）に新しいオプションが追加されました。タイル化可能な画像のタイル表示を保持できるようになり、後でマテリアルをタイル表示する時間が短縮されました。

## 互換性

Stagerにマテリアルを送信

Stagerに環境光を送信することは既に可能でした。 DesignerやPainterと同様に、ワンクリックで素材をStagerに送信できるようになりました。 この機能により、マテリアルを公開し、個別のファイルとしてStagerに読み込む必要がなくなりました（新しいマテリアルマネージャーを備えたStagerバージョン1.2.0が必要です）。
