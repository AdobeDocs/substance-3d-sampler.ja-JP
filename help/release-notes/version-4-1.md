# バージョン4.1

<b>Substance 3D Sampler 4.1.0 </b><b>ペイントワープ</b>フィルターを使用した新しいコンテンツと、改良版の<b>刺しゅう</b>フィルターを導入します。 このアップデートには、3D キャプチャの機能強化が含まれています。

*リリース日： 2023年3月28日*

## ペイントワープ

ペイントワープフィルターを使用すると、2D ビュー上にカーブを描画してマテリアルをワープできます。\
角度補正オプションを使用すると、マテリアルを再調整して、シームレスなタイリング作業を簡単におこなうことができます。

## 刺繍

新しい刺繍ジェネレータを使用すると、単一の画像ベクターファイルまたは図面から刺繍パッチを作成できます。\
最大6色まで刺繍でき、複数のステッチ技術を組み合わせることができます。
