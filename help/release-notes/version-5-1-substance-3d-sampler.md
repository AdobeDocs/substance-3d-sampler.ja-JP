# バージョン5.1

![](../assets/welcome_digitization_tool.jpg)

<b>Substance 3D Sampler 5.1</b>の新しく改良されたツールを使用して、素材をキャプチャしてからデジタルツインを書き出すまでの時間を短縮しましょう。

主な新機能は次のとおりです。

## 構造化されたマテリアルを自動的にタイリング

シームレスなタイルを自動的に生成することで、布地などの構造化またはパターン化されたマテリアルの処理に要する時間を節約できます。

詳細については、*[こちら](../filters/tools/auto-tiling.md)*&#x200B;をご覧ください。

![](../assets/WhatsNew_Auto-tiling-5_1.jpg)

## 効率的なレイヤーワークフロー

重なったレイヤーを1つの統合レイヤー内で単一のマップセットに変換することで、統合レイヤーでパフォーマンスを向上させ、計算時間を短縮します。 ファイル名の変更や複製を行うことで、効率が向上します。

詳細については、*[こちら](../features-and-workflows/flatten-layers.md)*&#x200B;をご覧ください。

![](../assets/WhatsNew_Flatten-Layers-5_1.png)

## スキャン処理のための強力なツール

強化されたイコライザーおよびコピースタンプフィルターに加えて、ファブリック用の新しい自動折り目除去機能により、わずか数クリックで完全なスキャンを実現できます。素材がどんなに複雑であっても同様です。

![](../assets/WhatsNew_Equalize-5_1.jpg)

## HP Z Captis サポートを強化

Studioモードで粗さマップの作成と自動物理サイズ検出を行うことで、これまで以上に詳細で正確なマテリアルデジタルツインが得られます。

![](../assets/whatsnew-hp-z-captis-5-1.jpg)
