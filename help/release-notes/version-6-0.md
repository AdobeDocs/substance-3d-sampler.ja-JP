# バージョン6.0

ジャラペーニョ

![代替テキスト](../../help/assets/Sampler_splash_large.jpg)

このアップデートには、業界標準のOpenPBRのサポート、高度なマテリアルをすばやく作成できるマテリアルプリセット、オーサリングをより柔軟に行えるように再設計されたプロパティパネルが導入されています。

主な新機能は次のとおりです。

## Substance エコシステムの中核となる OpenPBR

Sampler 6.0は、業界の統合マテリアルモデルである[OpenPBR](../features-and-workflows/openpbr.md)を採用しています。 幅広い3Dエコシステムでネイティブに理解されているマテリアルを構築します。1つの標準で、無限の互換性があります。ツール間のシームレスな相互運用性を実現するモデルにより、一度設計すれば推測を排除し、ワークフローを高速化できます。

![Substance 3D SamplerのOpenPBRマテリアル標準](../../help/assets/OpenPBR_1820x1024.jpg)

## ワンクリックで複雑なマテリアルを作成

深みのある複雑なマテリアルを瞬時に作成できます。 ファズ、半透明、クリアコートなどの新しいテンプレートを使用すると、複雑さを感じることなく、高度な物理効果を追加できます。 テンプレートを選択するだけで完成です。

詳細情報&#x200B;*[こちら](../interface/tools-and-widgets/material-creation-presets.md)*

![代替テキスト](../../help/assets/Sampler_Complex_Materials.jpg)

## マテリアル作成用に構築

Sampler 6.0は、高品質のデジタルツイン素材の作成など、最も重要なことについて、全体的なエクスペリエンスを向上させます。 すべての更新と新機能は、手間を省き、時間を節約し、真に価値を追加するワークフローの部分に集中できるように設計されています。

![代替テキスト](../../help/assets/Sampler_built_for_material_creation.jpg)

## 制御用に作成された新しいレイヤースタック

資料の管理をしなさい。 再設計されたプロパティパネルを使用すると、チャンネルごとにフィルターをターゲットにできるため、余分な手順を踏むことなく、正確な編集を行うことができます。

詳細情報&#x200B;*[こちら](../interface/panels/properties-panel.md)*

![代替テキスト](../../help/assets/Sampler_Infographic_1920x1080.png)

## これまで以上に素早くマテリアルをキャプチャ

Samplerでは、HP Z Captisのキャプチャをワンクリックで起動できるようになりました。目標範囲は自動的に検出され、必要に応じて回転します。また、焦点と光の強さを自動的に制御するため、少ない設定でシャープで一貫性のあるマップを取得できます。

詳細情報&#x200B;*[こちら](../pipeline-and-integrations/hp-z-captis-support/your-first-capture-step-by-step.md)*

![代替テキスト](../../help/assets/Captis_capture_optimization.JPG)
