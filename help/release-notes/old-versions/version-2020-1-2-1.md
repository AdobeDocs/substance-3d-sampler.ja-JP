# バージョン2020.1(2.1)

**Substance Alchemist 2020.1 「ティラミス」**&#x200B;では、レンダラーやゲームエンジン用に直接パックされたマテリアルを書き出すことができます。 デフォルトでは、Unity HDRP、Unreal Engine 4、Blender、Vray-Nextなど、15の書き出しプリセットが利用できます。

新しい構成ファイルと、更新チェッカーのコントロールが追加されました。

リリース日： *2020年3月12日*

## 主な機能

### 新しいエクスポータウィンドウ

![](../../assets/header-exporter.png)

書き出しウィンドウが修正され、いくつかの新機能を備えた新しいインターフェイスが導入されました。

* **エクスポートプリセットを使用して、特定のレンダラーまたはゲームエンジンのテクスチャをパックします**&#x200B;エクスポートプロセスで、特定のサードパーティアプリケーションのテクスチャを変換、パック、および名前を付けるエクスポートプリセットの一覧から、構成を選択できるようになりました。 この変換の結果は、インターフェイスの右側にあるチャンネルリストに表示されます。\
  新しい書き出しには、デフォルトで次のプリセットが含まれています。

  * Unreal Engine 4
  * Unity標準
  * Unity HDRP
  * ブレンダーサイクル/イベント
  * アーノルド5
  * コロナレンダリング
  * Enscape
  * Keyshot 9
  * Redshift
  * 次を表示
  * Lens Studio
  * Spark AR Studio
  * PBR Specular/PBRメタリックの粗さによる光沢

  ![](../../assets/exporter-preset-list.png)
* **マテリアルの名前を含むサブフォルダを作成します**\
  複数のマテリアルを共通の場所に書き出す際に、サブフォルダーを作成できるようになりました
* **書き出し設定は、次の書き出しで保存および復元されます**\
  書き出しウィンドウを再度開くと、以前に使用した書き出し設定も再利用されるため、操作が簡単になります。 マテリアルを簡単かつ迅速に再書き出しできます。
* **カスタム書き出しプリセットの作成、読み込み、および管理**\
  カスタムの書き出しプリセットを作成することもできます。 ドキュメントを作成および管理する方法については、次のドキュメントページを参照してください。

  * [カスタムプリセットの管理](https://helpx.adobe.com/substance-3d/unlisted/documentation/sadoc/creating-and-importing-custom-presets-188976295.html)
  * [プリセットの管理](../../getting-started/export/managing-presets.md)

### アプリケーションの構成

![](../../assets/header-config.jpg)

（[Unsplash](https://unsplash.com/?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText)の[Fabian Grohs](https://unsplash.com/@grohsfabian?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText)による写真）

これで、設定ファイルを使用してSubstance Alchemistを設定できます。 これにより、例えばスタジオ内など、複数のコンピューター間でアプリケーションを簡単にセットアップできます。 設定ファイルは、デフォルトのリソースと、リンクされたフォルダーのリストを定義します。

構成ファイルの作成方法と使用方法の詳細については、専用の[ドキュメントページ](https://helpx.adobe.com/substance-3d/unlisted/documentation/sadoc/resources-configuration-file-188976187.html)を参照してください。

### その他の改善

![](../../assets/header-checker.png)

このリリースでは、ワークフローに関するいくつかの新しい機能強化が提供されています。

* **2Dビューのフォーカス**\
  3Dビューと同様に、「F」ショートカットを使用して2Dビューをリセットし、中央に配置できるようになりました。
* **最後のプロジェクトを再度開く**\
  コンテンツ作成を簡単かつ迅速に行うために、最後に使用したプロジェクトが再び開くようになりました。 Create labは、アプリケーションを開いたときのデフォルトモードにもなりました。
* **チェッカー構成の更新**\
  新しいバージョンが使用可能になった場合に通知を受け取るかどうかを定義します。 詳細については、専用の[ドキュメントページ](../../technical-support/configuration/update-checker.md)を参照してください。

### 新規コンテンツ

![](../../assets/header-content.jpg)

一部のフィルターが改善され、スターターコンテンツも更新されました。

* **新しいスターターマテリアル**\
  いくつかの既存のマテリアルを新しいマテリアルに置き換えました。新しいマテリアルのリストを次に示します。
  * Alcantara細線維
  * カーペットの床
  * クリフロック
  * 銅
  * Dirt亀裂
  * ラフキャスト
  * テラコタ
  * 羊毛織物
  * 織物
* **ビットマップ2マテリアルフィルターを使用したメタリックコントロール**\
  Bitmap 2マテリアルフィルターが更新され、メタリックチャンネルをより細かく制御できるようになりました。 カスタムビットマップ入力を使用したり、均一なカラーを定義したりできるようになりました。
* **改善された調整フィルター**\
  調整フィルターがプロジェクトセットを使用して、PBRワークフローのSpecular/光沢を使用できるようになりました。
* **新しいAtlas Scatterパラメーター**\
  要素が下のマテリアルのHeightマップとどのようにブレンドされるかをより適切に制御できるように、いくつかの新しいパラメーターが追加されました。
