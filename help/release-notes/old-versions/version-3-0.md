# バージョン3.0

**Substance 3D Sampler 3.0.0**&#x200B;は、Adobe Creative Cloudに接続されたので、Substance Alchemistの新しい名前になりました。 これにより、UIの全面的なリワーク、環境光の作成のサポート、全面的にリワークされた新しいフィルター、Send To機能、ASMシェーダーサポートが提供されます。

リリース日： *23 June 2021*

## 主な機能

### 新しいインターフェイスとパネルの管理

新しい名前で、新しい外観が付属しています。 SamplerのUIが全面的に改良され、カスタマイズが強化され、アクセスが容易になりました。

![](../../assets/ui-dualscreen.jpg){width="600px"}

パネルはドッキングとドッキング解除が可能で、デュアルスクリーン設定をフルに活用できます。

### 新規プロジェクトワークフロー

![](../../assets/ui-project-panel.png)

Samplerがプロジェクトで動作するようになりました。 [プロジェクトパネル](../../interface/panels/project-panel.md)では、プロジェクトごとにアセットを管理およびグループ化できます。 プロジェクトはSubstanceのSamplerファイルに保存され、簡単に共有できます。

### 新規アセットパネル

![](../../assets/image2021-6-22-17-58-15.png)

[アセットパネル](../../interface/panels/assets-panel.md)は、自分のコレクションと組み合わせた、リソースパネルの新しい、共通のデザインです。

* 3つのセクション：スターターアセット+アセット+接続されたローカルフォルダー
* 新しいアセットタイプのサポート：フィルターと画像
* 狭いビュー/広いビュー
* フィルターと検索フィルター

### 新しい環境光オーサリング

![](../../assets/idl.jpg){width="600px"}

Samplerでは、マテリアル以外のものも作成できるようになりました。 環境光は、[独自のフィルターのセット](../../filters/hdri-tools/hdri-tools.md)を持つ新しいタイプのアセットです。 [ブラケット360枚の写真](../../filters/hdri-tools/hdr-merge.md)から開始して、環境光[をゼロから](../../filters/hdri-tools/shape-light.md)作成するか、[既存のHDRファイルを編集](../../filters/hdri-tools/nadir-patch.md)します。

### 修正された新しいフィルター

![](../../assets/filter-all-filters.jpg){width="600px"}

既存のフィルターがすべて修正されました。

* スペック/グロスチャンネルのサポート。
* カスタムマスクのサポート
* 標準化されたパラメータ名
* ほぼすべてのフィルターのアイコン

補正フィルターは、Photoshopを模倣するために、機能に基づいて個別のフィルターに分割されています。

![](../../assets/filter-adjustment-filters.jpg)

いくつかの新しいフィルターが追加されました。

* [ワープの変形](../../filters/tools/warp-transform.md)
* [織り方](../../filters/generators/weave.md)
* [パネル](../../filters/generators/panel.md)

### 新しい送信機能

![](../../assets/image2021-6-22-18-2-10.png)

Samplerは、Substance 3D PainterおよびStagerを使用して、[マテリアルや光環境をワンクリックで簡単に共有](../../interface/panels/share-panel.md)できるようになりました。

### 新しいリアルタイムレンダリングエンジン

* ASMマテリアルのサポート。より多くのマテリアルチャネルを使用するアプリケーション間で一貫した外観を実現します。
* 2つの[リアルタイムエンジン](https://helpx.adobe.com/jp/substance-3d/unlisted/documentation/sadoc/viewer-settings-188973164.html)を切り替える
* メッシュ上のデフォルトテクスチャを制御する機能

### 全般的な改善

* 新しい言語
* アプリケーションの応答性
* 非正方形テクスチャのサポート
* ツール取り消し/やり直し
* 画像の読み込みレイヤーの画像へのカスタム使用の割り当て
* パラメーター値のリセット
* Windowsのタスクバーでの進捗状況の書き出し
