# バージョン0.8.0

**追加：**

* [リソース]マテリアルフォルダをローカルディスクに接続してミラー化する
* [リソース]マテリアルフォルダとそのサブフォルダを参照する
* [リソース]リソースをフルスクリーンで表示するには、別のウィンドウでマテリアルリソースパネルを切り離します
* [リソース]フォルダとサブフォルダのナビゲーションをサポートする新しいリソースパネルのレイアウト
* [リソース]ブレッドクラムを使用してフォルダー間を移動する
* [リソース]ローカルフォルダーと同期オプションを強制的に同期します。このオプションには、右クリックでアクセスできます
* [リソース]ローカルフォルダーの接続を切断します。切断オプションには右クリックでアクセスできます
* [管理] Substanceファイルの埋め込みタグを表示する
* [管理]マテリアルのタグを追加、編集、削除する
* [管理]マテリアルを評価する
* [レイヤー]パノラマ出力をサポート
* [レイヤー]画像読み込みレイヤーで画像入力を削除できます
* [レイヤー]新しく追加されたレイヤーの自動選択
* [レイヤー]レイヤーを削除した後、下のレイヤーを自動選択する
* [UX]別のラボに切り替えるときに、左パネルを表示したままにする
* [UX]空でないレイヤースタックに画像を読み込む場合は、ベースレイヤーを作成したり、マテリアルワークフローポップアップを開いたりしないでください
* [UI]新しいテキストフィールドのスタイル
* [UI]新しい検索ボックススタイル
* [UI]新しいパネルヘッダースタイル
* [UI]新しいビジー状態インジケータスタイル
* [UI]新規レイヤースタックの背景スタイル
* [UI] Adobe Cleanフォントを使用
* [UI]カラー入力パラメーターのスポイトアイコンのプレースホルダーを削除
* [パフォーマンス]ビジーインジケーターの最適化
* [コンテンツ]新しいパターンジェネレータフィルタ
* [コンテンツ]新しいぼかしフィルター

**修正済み：**

* [インスピレーション] 10色以上を使用するとクラッシュする
* [2Dビュー] 2Dビューのチャンネルリストのスクロールバーを修正します。
* [Viewer] 2の累乗以外の環境マップを読み込むとクラッシュする問題を修正
* [コンテンツ]エンボスおよび穿孔フィルターのカスタムパターンに対するPNGの読み込みの修正
* [書き出し]チャンネル書き出しで標準とHeightを16ビットに修正
* 同じ名前の2つのプリセットを持つマテリアルを読み込む際に無限ループが発生する問題を修正
* ベースマテリアルレイヤーでの長いファイルパスの表示の修正

**既知の問題：**

* 1つのマテリアルに複数の区切り文字を使用することはお勧めしません
* 古いNVIDIAドライバー（400.x未満）でDelighterがクラッシュする
* Delighterステージをすばやく表示トグルすることはお勧めしません
* 画像読み込みレイヤーのプロパティパネルにTIF画像が表示されない
* スライダーに特定の値を入力するときは、昏睡やポイントを無視することができます
* 「通常からHeight」フィルターは、MacOSでクラッシュする可能性があります
* macOSで終了時にランダムにクラッシュすることがある
