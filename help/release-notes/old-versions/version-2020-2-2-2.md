# バージョン2020.2(2.2)

**Substance Alchemist 2020.2 「Udon」**&#x200B;は、新しいAIを活用した画像からマテリアルへの変換プロセスを導入し、1つの画像の入力を完全なPBRマテリアルに変換し、マテリアル作成テンプレートを改善しました。ワークフローや使いやすさが大幅に向上し、新しいフィルターなどの新しいコンテンツにも対応しています。

リリース日： *2020年6月15日*

## 主な機能

### 画像からマテリアル（AI搭載）

![](../../assets/banner-ai-material.jpg)

**Image to Material**&#x200B;テンプレートには、**AI Powered**&#x200B;という名前の新しい設定があります。 この新しい設定により、1つの入力画像から高品質のPBRマテリアルを生成する際の結果が向上します。

AIを活用した設定では、機械学習を使用してシェイプやオブジェクトを認識し、Heightや通常の情報を正確に生成します。 この設定には、シャドウとハイライトを除去する明るさフィルターも含まれています。 この新しい設定は、地面、小石、樹皮、石、および自然光で照らされたその他の外部ベースの表面でトレーニングされたため、屋外材料に最適です。 今後のアップデートにより、サポート対象マテリアルの柔軟性と汎用性が向上します。 詳細については、[専用ドキュメントページ](../../filters/tools/image-to-material.md)を参照してください。

以下に、2つのアルゴリズムによって生成されたHeight情報とそのデフォルト値の比較を示します。

![](../../assets/image-material-comparison.jpg){width="800px"}

>[!NOTE]
>
> AIを利用した設定には、特定のハードウェアが必要です。 Nvidia GPUを搭載したWindowsおよびLinuxでのみ使用できます。 詳細については、[技術要件](../../getting-started/system-requirements.md)を参照してください。

### 新しいテクスチャ読み込みテンプレート

![](../../assets/banner-template.png)

画像読み込みポップアップウィンドウの改善に、いくつかの点があります。 **テクスチャの読み込み**&#x200B;という名前の新しい種類のプロセスもあります。

* **改善されたインターフェイス**\
  インターフェイスが更新され、使いやすさと学習が容易になりました。各オプションの詳細な説明も利用できます。
* **新しいテクスチャ読み込みオプション**\
  **テクスチャの読み込み**&#x200B;という名前の新しいオプションが使用できるようになり、これにより、画像のセットを、その名前に基づいて適切な出力チャンネルに直接読み込んで接続できるようになりました。 既存のイメージのグループからマテリアルを簡単に設定できます。 詳細については、[専用ドキュメントページ](../../features-and-workflows/texture-import.md)を参照してください。

### フィルターのマスク入力の新しい2Dペイント

![](../../assets/banner-2d-paint.jpg)

このバージョンでは、外部画像を読み込まずに、2Dビューでフィルターマスクを直接ペイントおよび編集できるようになりました。 ペイントが自動的にタイル化され、シームレスなマテリアルの作成が可能になります。

![](../../assets/2d-paint-demo-optim.gif){width="450px"}

* **2Dペイントモードに入ります**\
  2Dペイントモードを開始するには、フィルターのプロパティのマスク名の横にあるブラシアイコンをクリックします。

  ![](../../assets/brush-icon-1.png)
* **2Dペイントツールバー**\
  ペイントモード内では、2Dビューの上部に次の機能を持つ新しいツールバーが表示されます。

  * **ブラシの色**:マスクをペイントする際にブラシのグレースケール値を調整します。
  * **ブラシペンサイズ**:マスクをペイントするためのブラシサイズを調整します。
  * **マスクをリセット**：現在のマスクを黒にクリアします。ペイント情報はすべて失われます。
  * **描画を停止**: 2Dペイントモードを終了します。

  ![](../../assets/brush-toolbar.png)
* **キーボードショートカット**\
  ペイントモードでは、ペイントプロセスを高速化するために次のショートカットがサポートされています。

  * **X**:ブラシの現在のグレースケール値を反転します。
  * **Ctrl +マウスホイール**:ブラシのサイズを変更します。
  * **[または]**:ブラシのサイズを変更します。

### 新しいアトラスとデカールの作成モードのショートカット

![](../../assets/banner-decal.jpg)

新しい種類のSubstanceマテリアルを利用して、レイヤースタックでの設定を容易にするために、2つの新しい作成モードが追加されました。

* **デカールモード**\
  **Altキーを押しながらドラッグアンドドロップ**:コレクションからマテリアルをドラッグアンドドロップするときは、**Alt**&#x200B;を押したまま保持して、デカール投影モードでマテリアルを自動的に作成します。
* **アトラスモード**\
  **Shiftキーを押しながらドラッグ&amp;ドロップ**:コレクションからマテリアルをドラッグ&amp;ドロップするときは、Shiftキーを押しながらドラッグ&amp;ドロップすると、マテリアルがAtlas Scatterモードで自動的に作成されます。

### 新しい遠近法の補正ツール

![](../../assets/banner-persp-tool.jpg)

「**遠近法の補正**」という名前の新しいツールがフィルターリストに追加され、画像の遠近法を調整または補正できるようになりました。

* **遠近法の補正**\
  このフィルターを使用すると、スキャンと写真画像のデフォルトを修正して、材料作成により適したものにすることができます。 フィルターには、画像の最初のコーナーを表す4つのコントロールポイントがあります。 ポイントを移動して、遠近感を調整/補正します。

  ![](../../assets/pers-filter-list.png)

### カラーウィジェットの改善

![](../../assets/banner-color-widget.png)

パラメーターパネルに表示されるカラーウィジェットに、さらに多くのコントロールが追加されました。

* **カラー値のツールヒント**\
  マウスをカラーウィジェットの上に置くと、現在のカラー値（16進数形式）を説明するツールヒントが表示されます。
* **右クリック操作**\
  カラーウィジェットを右クリックすると、次のアクションを含む新しいコンテキストメニューが表示されます。
  * **クリア**:カラーを黒に設定し、アルファ値をゼロに設定します。
  * **コピー**:ウィジェットの現在のカラー値をメモリにコピーします。
  * **貼り付け**:メモリ内の現在のカラー値をウィジェットに貼り付けます。

### 新規コンテンツ

![](../../assets/banner-content.jpg)

このバージョンには、新しいさまざまなコンテンツが数多く追加されています。

* **新しい既定のメッシュ**\
  ビューポートでマテリアルを表示するために、次の3つの新しいメッシュが使用できます。
  * 靴型
  * 男性のTシャツ
  * 女性のTシャツ
* **新しいフィルター**\
  このバージョンでは、次の5つの新しいフィルターを使用できます。
  * 亀裂
  * コケ
  * キルトステッチ
  * 床タイル
  * PBR 検証
* **新しい描画モード**
* フィルターおよびその他のツールが、**チャンネル単位の描画モード**&#x200B;という名前の新しい描画モードをサポートするようになりました。 このモードを有効にすると、プロパティパネルで各チャンネルのブレンド操作を微調整できます。
* **プリセットの書き出し**\
  このリリースには、新規および更新された書き出しプリセットが含まれています。
  * VStitcher
  * クロー
  * Unity HDRPテンプレートでのDetailMapサポート
