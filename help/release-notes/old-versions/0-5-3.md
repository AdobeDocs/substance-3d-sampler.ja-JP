# 0.5.3

リリース日： **2019/03/19**

追加：

* リソースパネルでのマテリアル名による検索
* [UI] クローンツールの新しいUI、ブラシサイズの表示
* [UI]非表示ステージの選択と削除
* [UI]新しいテキストフィールドUI
* [ヘルプ] Substance Source、Substance share、Substanceアカデミーのwebサイトにアクセスする
* [コンテンツ]ジェネレータとアトラスを含む新しい既定のマテリアル
* [コンテンツ]ビットマップからマテリアルへの更新
* [コンテンツ] Dirtの更新
* [コンテンツ] 錆の更新
* [コンテンツ]新しいエンボスフィルタ
* [コンテンツ]新しい刺繍フィルター
* [コンテンツ]新しい浸食フィルター
* [コンテンツ]新しい砂利ジェネレータ
* [コンテンツ]新しいペイントフィルタ
* [コンテンツ]新しい寄木パターンフィルタ
* [コンテンツ]新しい舗装パターンフィルタ
* [コンテンツ]新しい穿孔フィルタ
* [コンテンツ]新しいスプラッタフィルタ
* 【内容】新繊維ウエアフィルター
* [コンテンツ]新しい変形フィルタ

修正：

* [ビューポート] X上にタイリングx2を持つ球メッシュ
* [ビューポート]独自の環境をロードするとクラッシュする
* [ビューポート]環境マップは露光量も使用するようになりました
* [ビューポート] F ショートカットでカメラ角度がリセットされない
* [書き出し] SBSの書き出しは最新Substance Designer 2018.3.3で動作します
* [書き出し] SBSAR書き出しでは、Substance Sourceのマテリアルと同じガイドラインが適用されます
* [UI]スクロールバーをドラッグできる
* フォルダーおよびファイルパスでは、特殊文字がサポートされています
* マテリアルを保存すると、サムネールが再生成される

既知の問題：

* 1つのマテリアルに複数の区切り文字を使用することはお勧めしません
* 古いNVIDIAドライバー（400.x未満）でDelighterがクラッシュする
* Delighterステージの高速表示の切り替えは、パフォーマンスに影響します
* カスタム環境の読み込みが黒になることがある
* 画像読み込みレイヤーのプロパティパネルにTIF画像が表示されない
* スライダーに特定の値を入力するときは、昏睡やポイントを無視することができます
* 保存先の既定のコレクションは空にすることができます
