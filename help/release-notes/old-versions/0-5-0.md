# 0.5.0

リリース日： **2019/02/28**

追加：

* [レイヤスタック]レイヤの並べ替え
* [レイヤスタック]非表示レイヤを削除する
* [レイヤースタック]選択した位置にマテリアルを直接読み込む
* [レイヤスタック]新しいフィルタパラメータタイプとしてマテリアルを入力
* [パフォーマンス]パフォーマンス向上のためにSubstance engineの予算は動的である
* [パフォーマンス]特にMacOSでのOpenGLのパフォーマンスの向上
* [Data]新しいバージョンがリリースされた後のデータのアップグレードが高速になりました
* [コンテンツ] Windows 7およびWindows 8で利用可能なAI Delighter
* [コンテンツ] RTX GPUで利用可能なAI Delighter

修正：

* アプリケーションの終了時に発生する可能性のあるクラッシュを修正
* 大きなコレクションを書き出す場合に、書き出しポップアップを開く速度が速くなる

既知の問題：

* 1つのマテリアルに複数の区切り文字を使用することはお勧めしません
* 古いNVIDIAドライバー（400.x未満）でDelighterがクラッシュする
* Delighterステージの高速表示の切り替えは、パフォーマンスに影響します
* 独自の環境を読み込むときにクラッシュする
