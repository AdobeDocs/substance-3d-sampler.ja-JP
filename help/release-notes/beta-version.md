# ベータ版

このページには、Samplerのベータ版のチェンジログが含まれています。 ベータ版にアクセスする方法については、[FAQ](../faq.md)を参照してください。

>[!NOTE]
>
>Samplerのベータ版は提供されていない場合があります。 今後ベータ版がリリースされる時期を確認するには、Substance 3Dのソーシャルチャネルに従ってください。


## 4.4.0 Beta – テキストからテクスチャ

Adobe Fireflyを利用したテクスチャへのテキストの追加を行います。これは、説明のみを使用してアーティストがテクスチャ画像を得るための新しい方法です。 この新機能により、アーティストのツールボックスはカスタム写真やストックフォトの読み込みだけでなく、Sampler内でテクスチャを作成する方法が提供されます。 すべてのテキストからテクスチャへの画像は正方形で、適切な遠近法でタイル表示でき、マテリアルの作成ワークフローに対応できます。
