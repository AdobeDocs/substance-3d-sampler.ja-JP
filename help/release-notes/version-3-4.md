# バージョン3.4

**Substance 3D Sampler 3.4.0**&#x200B;は、3Dワークフローの速度と品質を向上させるために設計された一連の新機能を導入します。

*リリース日： 2022年9月6日*

## 主な機能

## 表示されるパラメーター

CLO、UE5、Blender、Photoshop、Illustratorなど、SBSARファイルをサポートするソフトウェア内のパラメトリックマテリアルを変更します。\
Samplerのアセットパラメーターを表示する新しい機能により、反復を高速化し、Samplerと他のソフトウェアの間の行きや行き来を排除できるようになりました。

ピンをクリックするだけで、マテリアルのパラメーターを表示できます。

カラードットは、表示されるパラメーターや様々なパネルに移動するのに役立ちます。

## Pythonオーサリング

プラグインとスクリプトを作成できるようになりました。これにより、インターフェイスをカスタマイズし、Samplerをパイプラインに統合し、全体的なワークフローを自由に設定できます。\
これにより、例えば、1回のクリックで複数のマテリアルを書き出すように、繰り返し作業を自動化できるスクリプトを作成できます。

最初のプラグインまたはスクリプトを作成する方法については、[こちら](../scripting-and-development/scripting-and-development.md)を参照してください。

## CLO物理プロパティ

物理シミュレーションでリアルに動作するテキスタイルを作成できるようになりました。 これは、曲げ、せん断、摩擦などのファブリックの物理的なプロパティを入力することによって実現されます。\
今回のアップデートでは、SBSARにメタデータ内の物理情報が含まれ、マテリアルがリアルに反応するようにCLOが使用します。

## 画像からマテリアルへ（AI搭載）

画像をマテリアルに変換（AI搭載）がMacOSで利用できるようになり、Apple Siliconデバイスでネイティブに実行されます。
