# バージョン4.0

**Substance 3D Sampler 4.0**&#x200B;では、被写体の自動マスク、テクスチャマッピング、ジオメトリのデシメーションを使用して、実際の画像を使用して3Dオブジェクトを作成できます。 このバージョンでは、Python APIの新しい可能性として、UXの改善が紹介されています。

*リリース日： 2023年1月31日*

![](../assets/main-promo.jpg)

## 3D キャプチャ

Substance 3D Sampler 4.0では、画像から3Dオブジェクトを作成できるようになりました。

写真測量機能を統合しました。 写真測量は、画像から計測値を取得する技術的なプロセスです。 一連の写真から3Dメッシュを作成するのは、Samplerの手法です。

まず、被写体の見える面を捉えた一連の写真を使用するだけです。スマートフォンやDLSRカメラが最適です。

手順を追ったワークフローについては、[こちら](../features-and-workflows/3d-capture.md)をご覧ください。

## ハイライト

### 自動マスク

3D キャプチャするオブジェクトの背景を削除します。 「マスク」タブで画像を読み込んだ後、オブジェクトの自動生成マスクを作成します。

マスクを使用することには、多くの利点があります。 これにより、特徴を検出し、マスクされていない領域のみを再構築できます。

![](../assets/release-page-masking.jpg){width="500px"}

### 再構築領域を定義

画像の整列後にバウンディングボックスをアクティブにするには、目標範囲を切り替えます。 再構築する正確な領域を設定して揃えます。

![](../assets/3d-capture-bounding-box-modified.png){width="500px"}

### 連携された後処理

3Dオブジェクトが再構築されたら、自動デシメーション、UVアンラップ、ベイク処理を使用して結果を最適化します。

後処理により、メッシュとテクスチャをニーズや使用方法に合わせて調整、最適化することができます。

再構築の結果、数百万のポリゴンと最大16Kのテクスチャを持つメッシュを生成できます。 これは、レンダリング、リアルタイム、AR体験に最適化されていない場合があります。

後処理のステップは、次の4つのステップを自動的にチェーン化します。

* Decimation
* UVアンラップ
* 再投影
* ベイク処理

![](../assets/release-page-post-processing.jpg){width="500px"}

### 主なファイル形式に書き出し

再構築した3Dオブジェクトを、必要なときにどこでも使用できるように、すべての標準ファイル形式で書き出します。

![](../assets/v4-0-0-export.jpg){width="500px"}

## ビューポート

2Dおよび3Dビューポートは、サイズ変更、入れ替え、上下に重ねることができます。

![](../assets/screenshot-2023-01-25-at-16-23-09.png){width="500px"}

## スクリプティング

エクスポート機能を4つに分割しました。

* マテリアルのエクスポート： `export_material`
* 環境光のエクスポート： `export_environment_light`
* テクスチャ付きまたはテクスチャなしのメッシュのエクスポート： `export_mesh`または`export_3d_object`

特定の使用法のテクスチャをインポートする新しい関数が追加されました： `import_textures`

Samplerは、次の2つの環境変数で定義されたパスに保存されている起動スクリプトとプラグインで読み込まれるようになりました。

* `SAMPLER_PLUGIN_PATH`
* `SAMPLER_SCRIPT_PATH`
