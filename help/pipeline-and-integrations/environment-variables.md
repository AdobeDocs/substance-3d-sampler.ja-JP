# 環境変数

このページには、アプリケーションのデフォルトの動作を上書きするために使用できる環境変数が一覧表示されます。

| 変数 | 説明 |
| --- | --- |
| **SUBSTANCE\_SAMPLER\_ライセンス** | 値： license.keyファイルへのパスアプリケーションがライセンスファイルをロードする場所を上書きします。  **注意：** 3.0より前のバージョンでは、代わりにこの変数名を使用します：**SUBSTANCE\_ALCHEMIST\_ライセンス** |
