# 低仕様モード

![](../assets/v6.1/6_1-Checked.png)

お使いのハードウェアがSamplerの[最小要件](../getting-started/system-requirements.md)を満たしていない場合、Samplerは自動的に低仕様モードで起動します。これは、設定を変更するオプションがない場合は[パフォーマンスモード](performance-mode.md)のように動作します。

## 低仕様モードの制限

低仕様モードでは、すべての機能が無効になり、最大プレビュー解像度が2048 ～ 2048の&#x200B;**パフォーマンスモード**&#x200B;が自動的×オンになります。

低仕様モードでは以下が無効になります。

* **ディスプレイスメント**
* **シャドウ**
* **パストレース**

また、低仕様モードでは、2048px×2048pxを超える書き出しが防止されます。

![](../assets/low-spec-mode-export-message.png)

*このメッセージは、**低仕様モード**で&#x200B;**書き出しウィンドウ**に表示され、追加情報を提供します。*

## 低仕様モードが有効になっているかどうかを確認する方法を教えてください。

Samplerを起動したときに、ハードウェアが最小要件を満たしていない場合は、満たしていない要件を示すウィンドウが表示され、Samplerを引き続き起動できます。

次の図に、VRAMの容量が8 GB未満のマシンの例を示します。

![](../assets/low-device-specs-popup.png)

**いずれにせよ起動**&#x200B;することを選択した場合、Samplerは&#x200B;**低仕様モード**&#x200B;で起動します。 上記のメッセージのチェックボックスを使用して、表示せずに起動した場合でも、以降の起動時に次のバナーが表示されます。

![](../assets/low-spec-mode-banner.png)

最後に、**低仕様モード**&#x200B;が有効になっている間は、パフォーマンスモードをオフにしたり、パフォーマンスモードの設定を調整したりすることはできません。

![](../assets/performance-mode-locked.png)
