# パフォーマンスモード

パフォーマンスモードでは、ワークフローの速度を低下させるあらゆる設定（解像度制限、シャドウ、ディスプレイスメント画質、パストレーシング）をまとめることができます。 不要なものをオフにし、特に軽量のハードウェアで必要な応答性を得ます。

>[!NOTE]
>
> お使いのハードウェアがSamplerの[最小要件](../getting-started/system-requirements.md)を満たしていない場合、Samplerは[低仕様モード](low-spec-mode.md)で自動的に起動します。これは、設定を変更するオプションがない場合は、パフォーマンスモードと同様に動作します。

## パフォーマンスモードを切り替え

**Samplerウィンドウ**&#x200B;の右上にある&#x200B;**パフォーマンスモードボタン**&#x200B;でパフォーマンスモードを切り替えることができます。

![](../assets/performance-mode-button.png)

## パフォーマンスモード設定の変更

**[パフォーマンスモード]ボタン**&#x200B;の横にあるドロップダウンを使用して、パフォーマンスモードで有効にする制限を制御します。

![](../assets/performance-mode-settings.png)

| 設定 | 説明 |
| --- | --- |
| **プレビューの最大解像度** | パフォーマンスモードでは、プレビュー解像度が低くなり、レンダリングが高速になります。 読み込まれたアセットやドキュメントの解像度は変わらず、ビューポートレンダラーの画質が変わります。 |
| **ディスプレイスメントの品質を無効にする** | この設定を有効にすると、**パフォーマンスモード**&#x200B;は&#x200B;**ディスプレイスメントの品質値**&#x200B;を0にロックし、ビューポートのディスプレイスメント効果を無効にします。 タイルや細かい布地などの滑らかなマテリアルの場合、視覚的な影響は最小限に抑えられますが、パフォーマンスを大幅に向上させることができます。 |
| **シャドウを無効にする** | メッシュとディスプレイスされたマテリアルはシャドウをキャストできるため、パフォーマンスを犠牲にしてよりリアルなイメージを作成できます。 **シャドウを無効にする**&#x200B;をオンにすると、パフォーマンスモードですべてのシャドウ処理が無効になり、パフォーマンスが向上します。 |
| **パストレースを無効にする** | パストレーシングは強力なレンダリング手法であり、シーンを跳ね返る光の軌跡を追跡することで、フォトリアリスティックなレンダリングを実現します。 ただし、パスのトレースは高価です。 **[パスのトレースを無効にする]**&#x200B;がオンになっている場合、パフォーマンスモードでは、**3D ビューポート**&#x200B;のパスのトレースを有効にするオプションが無効になります。 |

>[!NOTE]
>
> パストレースには、**3D ビューポートツールバー**&#x200B;からアクセスできます。
>
> ![](../assets/enable-path-tracing.png)
>
> パストレースが有効になっていない場合、**パストレースを無効にする**&#x200B;のみをオンにしてパフォーマンスモードをオンにしても、効果はありません。
