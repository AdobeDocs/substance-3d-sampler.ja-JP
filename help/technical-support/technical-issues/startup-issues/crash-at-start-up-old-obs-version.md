# 起動時のクラッシュ – 古いOBSバージョン

古い[OBS](https://obsproject.com/fr)バージョンがインストールされていると、アプリケーションが起動時にクラッシュする可能性があります。

この問題を解決するには、[OBSバージョン](https://obsproject.com/fr/download)を更新するか、アンインストールしてください。
