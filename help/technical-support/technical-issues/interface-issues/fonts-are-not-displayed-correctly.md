# フォントが正しく表示されない

Windows 10 Enterpriseを使用していて、[信頼できないフォントをブロック](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise)する機能を使用する場合、この[チュートリアル](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html)に従って、フォントブロックの対象として信頼できないアプリの一覧からSamplerを除外できます。
