# 画像のマテリアルへの変換とDelighterがありません

システムが[必要システム構成](https://substance3d.adobe.com/documentation/display/DRAFTSAMPLER/.System+requirements+vDraftVersion)を満たしていない場合、**画像からマテリアル（AI搭載）**&#x200B;および&#x200B;**採光**&#x200B;がフィルターリストに表示されない可能性があります。
