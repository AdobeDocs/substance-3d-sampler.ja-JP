# 画像をマテリアルまたは採光に使用するとクラッシュする

**Image To Material （AI搭載）**&#x200B;および&#x200B;**Delighter**&#x200B;フィルターには、多くの使用可能なVRAM （少なくとも1GB）が必要です。

2 GBのVRAMのみを搭載したGPUカードを2K/4K解像度で動作している場合、フィルターの実行に十分なメモリを割り当てられず、クラッシュが発生する可能性があります。
